## IoT Components

   <a href="#AboutIoTHub">Microsoft's Azure IoT Hub</a> is the foundational <strong>PaaS (Plattform as a Service)</strong> offering for device connectivity, management and communication.
   If an IoT device does not support standard protocols (AMPQ, MQTT and HTTP), then incoming and outgoing traffic can be adapted using the <a target="_blank" href="https://github.com/Azure/azure-iot-protocol-gateway/blob/master/README.md">Azure IoT Protocol Gateway</a>

   <a target="_blank" href="https://azure.microsoft.com/en-us/services/iot-central/demo/">Azure IoT Central</a> provides <strong>Software as a Service (SaaS)</strong> by using an IoT Hub under the hood to provide <strong>templates</strong> that use a ready-made model-based approach to build enterprise-grade IoT solutions -- without requiring expertise in cloud-solution development. 

   Azure IoT solution <a target="_blank" href="https://azure.microsoft.com/en-us/features/iot-accelerators/">accelerators</a> are built on Azure IoT Hub to accelerate the development of custom IoT solutions.

   <a target="_blank" href="https://azure.microsoft.com/en-us/services/iot-edge/">Azure IoT Edge</a> extends cloud intelligence and <strong>analytics</strong> to <a href="#Edge_Devices">edge devices</a> at a local level (like AWS Greengrass), so devices can run offline. The <a target="_blank" href="https://azure.microsoft.com/en-us/features/iot-accelerators/">connected device simulation accelerator</a> allows test-run of solutions with tens of thousands of simulated devices.
   IoT Edge has extremely low latency and near real-time response potential. Edge works the <a target="_blank" href="https://github.com/Azure/ai-toolkit-iot-edge">AI Toolkit for Azure IoT Edge</a> to run AI and ML tasks such as image recognition and complex event processing. 
   

   ### IoT Pricing - Free first month

   How much does all this cost?

   IoT Hub is grouped into four tiers, up to the high throughput S3 tier for up to 300,000,000 messages per day. 
   More can be purchased. 
   
   After a one-month free trial period, the "F1 Free Tier" allows 8,000 free messages (of .5 KB each) a day.

   NOTE: Although messages can be up to 512 KB, they are billed in 4 KB blocks.

   <a target="_blank" href="https://azure.microsoft.com/en-us/pricing/details/iot-hub/"> 
   The first paid tier</a> of
   400,000 messages per month / $50 = 0.000125 per message (about 1 cent).
