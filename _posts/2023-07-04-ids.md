## Why an Intrusion Detection System?

> If even the NSA, Equifax, and others (with a lot of people protecting their data) have been hacked, it's a question of time before someone accesses your data without permission. Even if you have proven that your backups can be restored in a timely manner, you need alerts from an Intrusion Detection System to know when to reset passwords and fall back on backups.

This is about immediately identifying and responding to threats on your network.

Among PCI compliance validation <a target="_blank" href="https://listings.pcisecuritystandards.org/documents/PCI_DSS-QRG-v3_2_1.pdf">PDF</a> are:

   <ul>\5. Protect all systems against malware and regularly update anti-virus software.<br />
   \10. Track and monitor all access to network resources and cardholder data.<br />
   \11. Regularly test security systems and processes.
   </ul>

Cloud IDS provides the evidence that auditors review as the basis for issuing an annual <a target="_blank" href="https://docs-prv.pcisecuritystandards.org/PCI%20DSS/Reporting%20Template%20or%20Form/PCI-DSS-v3-2-1-ROC-Reporting-Template-r2.pdf">Report on Compliance (ROC)</a>, which include:
   * Examine documentation
   * Interview personnel
   * Examine/observe live data
   * Observe processes being performed (of quarterly scan results)
   * Observe the physical environment
   * Interactive testing
   <br /><br />

   ### Eicar File Detected

   EICAR is an acronym for "European Institute for Computer Antivirus Research".
   Along with the Computer Antivirus Research Organization, 
   EICAR created the <a target="_blank" href="https://www.wikiwand.com/en/EICAR_test_file">"Eicar file"</a> for testing anti-virus software features without resorting to installing harmful real malware. 
   The Eicar file should be recognized among other signatures of virus infection, even when stored in a compressed file. 

   The EICAR file is executable. When run, it simply prints out "EICAR-STANDARD-ANTIVIRUS-TEST-FILE!".

   Like some real malware, it makes use of self-modifying code.

   The "Eicar file" is referenced by <a target="_blank" href="https://www.amtso.org/standards/">Testing Protocol Standards</a> developed by the <a target="_blank" href="https://www.amtso.org/about-amtso/">Antimalware Testing Standards Organization</a> of security vendors and expert test labs from around the world.

   <a target="_blank" href="https://www.amtso.org/standards/">AMTSO Feature Settings Checks</a>.

   Not all virus scanners recognize it, though.
