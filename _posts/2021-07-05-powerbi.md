Author -> Publish -> Consume

Microsoft defines two types of users: Business users who interact with content created, then shared by designers.

The most common flow of activity:

1. Bring <strong>data into Power BI Desktop</strong> and <strong>create a report</strong> (based on template?).
2. Publish to the Power BI service, where you can create new visualizations or build dashboards.
3. Share <a href="#Dashboards">dashboards</a> with others, especially people who are on the go.
4. View and interact with <strong>shared dashboards and reports</strong> in Power BI <strong>Mobile</strong> apps.

## GUI Building blocks

The basic building blocks in Power BI:

   * Each app from the AppSource is a collection of ready-made visuals, pre-arranged in dashboards and reports.

   * Visualizations – Visual representations of data, sometimes just called visuals
   * <a href="#Workflows">Workflows</a>

   * Datasets – Collections of data that Power BI uses to create visualizations
   * <a href="#Connectors">Connectors</a> to external datasets in various data formats

   * Reports – Collections of visuals from a dataset, spanning one or more pages
   * <a href="#Dashboard">Dashboards</a> – Single-page collections of visuals built from reports

   * The <strong>canvas</strong> is the area in the center of the Power BI service.
   * Tiles within Dashboard

Maths & Statistical Functions

Notice the "X" functions:

* SUM(<em>column</em>) Adds all the numbers in a column.
* SUMX(<em>table</em>, <em>expression</em>) Returns the sum of an expression evaluated for each row in a table.
* AVERAGE(<em>column</em>) Returns the average (arithmetic mean) of all the numbers in a column.
* AVERAGEX(<em>table</em>, <em>expression</em>) Calculates the average (arithmetic mean) of a set of expressions evaluated over a table.
* MEDIAN(<em>column</em>) Returns the median of a column.
* MEDIANX(<em>table</em>, <em>expression</em>) Calculates the median of a set of expressions evaluated over a table.
* GEOMEAN(<em>column</em>) Calculates the geometric mean of a column.
* GEOMEANX(<em>table</em>, <em>expression</em>) Calculates the geometric mean of a set of expressions evaluated over a table.
* COUNT(<em>column</em>) Returns the number of cells in a column that contains non-blank values.
* COUNTX(<em>table</em>, <em>expression</em>) Counts the number of rows from an expression that evaluates to a non-blank value.
* DIVIDE(<em>numerator</em>, <em>denominator</em> [,<em>alternateresult</em>]) Performs division and returns alternate result or BLANK() on division by 0.
* MIN(<em>column</em>) Returns a minimum value of a column.
* MAX(<em>column</em>) Returns a maximum value of a column.
* COUNTROWS([<em>table</em>]) Counts the number of rows in a table.
* DISTINCTCOUNT(<em>column</em>) Counts the number of distinct values in a column.
* RANKX(<em>table</em>, <em>expression</em>[, <em>value</em>[, <em>order</em>[, <em>ties</em>]]]) Returns the ranking of a number in a list of numbers for each row in the table argument.

Filter Functions:

* FILTER(<em>table</em>, <em>filter</em>) Returns a table that is a subset of another table or expression.
* CALCULATE(<em>expression</em>[, <em>filter1</em> [, <em>filter2</em> [, …]]]) Evaluates an expression in a filter context.
* HASONEVALUE(<em>columnName</em>) Returns TRUE when the context for columnName has been filtered down to one distinct value only. Otherwise, it is FALSE.
* ALLNOBLANKROW(<em>table</em> &vert; <em>column</em>[, <em>column</em>[, <em>column</em>[,…]]]) Returns a table that is a subset of another table or expression.
* ALL([<em>table</em> &vert; <em>column</em>[, <em>column</em>[, <em>column</em>[,…]]]]) Returns all the rows in a table, or all the values in a column, ignoring any filters that might have been applied.
* ALLEXCEPT(<em>table</em>, <em>column</em>[, <em>column</em>[,..]]) Returns all the rows in a table except for those rows that are affected by the specified column filters.
* REMOVEFILTERS([<em>table</em> &vert;  <em>column</em>][, <em>column</em>[, <em>column</em>[,…]]]]) Clear all filters from designated tables or columns.

Logical Functions
* IF(<em>logical_test</em>, <em>value_if_true</em>[, <em>value_if_false</em>]) Checks a condition, and returns a certain value depending on whether it is true or false.
* AND(<em>logical 1</em>, <em>logical 2</em>) Checks whether both arguments are TRUE, and returns TRUE if both arguments are TRUE. Otherwise, it returns FALSE.
* OR(<em>logical 1</em>, <em>logical 2</em>) Checks whether one of the arguments is TRUE to return TRUE. The function returns FALSE if both arguments are FALSE.
* NOT(<em>logical</em>) Changes TRUE to FALSE and vice versa.
* SWITCH(<em>expression</em>, <em>value</em>, <em>result</em>[, <em>value</em>, <em>result</em>]…[, <em>else</em>]) Evaluates an expression against a list of values and returns one of possible results
* IFERROR(<em>value</em>, <em>value_if_error</em>) Returns value_if_error if the first expression is an error and the value of the expression itself otherwise.

Date & Time Functions

* CALENDAR(<em>start_date</em>, <em>end_date</em>) Returns a table with a single column named "Date" that contains a contiguous set of dates.
* DATE(<em>year</em>, <em>month</em>, <em>day</em>) Returns the specified date in datetime format.
* DATEDIFF(<em>date_1</em>, <em>date_2</em>, <em>interval</em>) Returns the number of units between two dates as defined in <em>interval</em>.
* DATEVALUE(<em>date_text</em>) Converts a date in text to a date in datetime format.
* DAY(<em>date</em>) Returns a number from 1 to 31 representing the day of the month.
* WEEKNUM(<em>date</em>) Returns weeknumber in the year.
* MONTH(<em>date</em>) Returns a number from 1 to 12 representing a month.
* QUARTER(<em>date</em>) Returns a number from 1 to 4 representing a quarter.

Time Intelligence Functions

* DATEADD(<em>dates</em>, <em>number_of_intervals</em>, <em>interval</em>) Moves a date by a specific interval.
* DATESBETWEEN(<em>dates</em>, <em>date_1</em>, <em>date_2</em>) Returns the dates between specified dates.
* TOTALYTD(<em>expression</em>, <em>dates</em>[, <em>filter</em>][, <em>year_end_date</em>]) Evaluates the year-to-date value of the expression in the current context.
* SAMEPERIODLASTYEAR(<em>dates</em>) Returns a table that contains a column of dates shifted one year back in time.
* STARTOFMONTH(<em>dates</em>) // ENDOFMONTH(<em>dates</em>) Returns the start // end of the month.
* STARTOFQUARTER(<em>dates</em>) // ENDOFQUARTER(<em>dates</em>) Returns the start // end of the quarter.
* STARTOFYEAR(<em>dates</em>) // ENDOFYEAR(<em>dates</em>) Returns the start // end of the quarter.
Relationship Functions
* CROSSFILTER(<em>left_column</em>, <em>right_column</em>, <em>crossfiltertype</em>) Specifies the cross-filtering direction to be used in a calculation.
* RELATED(<em>column</em>) Returns a related value from another table.

Table Manipulation Functions

* SUMMARIZE(<em>table</em>, <em>groupBy_columnName</em>[, <em>groupBy_columnName</em>]…[, <em>name</em>, <em>expression</em>]…) Returns a summary table for the requested totals over a set of groups.
* DISTINCT(<em>table</em>) Returns a table by removing duplicate rows from another table or expression.
* ADDCOLUMNS(<em>table</em>, <em>name</em>, <em>expression</em>[, <em>name</em>, <em>expression</em>]…) Adds calculated columns to the given table or table expression.
* SELECTCOLUMNS(<em>table</em>, <em>name</em>, <em>expression</em>[, <em>name</em>, <em>expression</em>]…) Selects calculated columns from the given table or table expression.
* GROUPBY(<em>table</em> [, <em>groupBy_columnName</em>[, [<em>column_name</em>] [<em>expression</em>]]…) Create a summary of the input table grouped by specific columns.
* INTERSECT(<em>left_table</em>, <em>right_table</em>) Returns the rows of the left-side table that appear in the right-side table.
* NATURALINNERJOIN(<em>left_table</em>, <em>right_table</em>) Joins two tables using an inner join.
* NATURALLEFTOUTERJOIN(<em>left_table</em>, <em>right_table</em>) Joins two tables using a left outer join.
* UNION(<em>table</em>, <em>table</em>[, <em>table</em> [,…]]) Returns the union of tables with matching columns.

Text Functions

* EXACT(<em>text_1</em>, <em>text_2</em>) Checks if two strings are identical (EXACT() is case sensitive).
* FIND(<em>text_tofind</em>, <em>in_text</em>) Returns the starting position a text within another text (FIND() is case sensitive).
* FORMAT(<em>value</em>, <em>format</em>) Converts a value to a text in the specified number format.
* LEFT(<em>text</em>, <em>num_chars</em>) Returns the number of characters from the start of a string.
* RIGHT(<em>text</em>, <em>num_chars</em>) Returns the number of characters from the end of a string.
* LEN(<em>text</em>) Returns the number of characters in a string of text.
* LOWER(<em>text</em>) Converts all letters in a string to lowercase.
* UPPER(<em>text</em>) Converts all letters in a string to uppercase.
* TRIM(<em>text</em>) Remove all spaces from a text string.
* CONCATENATE(<em>text_1</em>, <em>text_2</em>) Joins two strings together into one string.
* SUBSTITUTE(<em>text</em>, <em>old_text</em>, <em>new_text</em>, <em>instance_num</em>) Replaces existing text with new text in a string.
* REPLACE(<em>old_text</em>, <em>start_posotion</em>, <em>num_chars</em>, <em>new_text</em>) Replaces part of a string with a new string.

Information Functions

* COLUMNSTATISTICS() Returns statistics regarding every column in every table. This function has no arguments.
* NAMEOF(<em>value</em>) Returns the column or measure name of a value.
* ISBLANK(<em>value</em>) // ISERROR(<em>value</em>) Returns whether the value is blank // an error.
* ISLOGICAL(<em>value</em>) Checks whether a value is logical or not.
* ISNUMBER(<em>value</em>) Checks whether a value is a number or not.
* ISFILTERED(<em>table</em> &vert; <em>column</em>) Returns true when there are direct filters on a column.
* ISCROSSFILTERED(<em>table</em> &vert; <em>column</em>) Returns true when there are crossfilters on a column.
* USERPRINCIPALNAME() Returns the user principal name or email address. This function has no arguments.

DAX Statements

* VAR(<em>name</em> = <em>expression</em>) Stores the result of an expression as a named variable. To return the variable, use RETURN after the variable is defined.
* COLUMN(<em>table</em>[<em>column</em>] = <em>expression</em>) Stores the result of an expression as a column in a table.
* ORDER BY(<em>table</em>[<em>column</em>]) Defines the sort order of a column. Every column can be sorted in ascending (ASC) or descending (DESC) way.

   )

IF(

         REMOVEFILTERS(Region[Region])
      )
   )
)
</pre>

<pre># Sales % Group measure definition
Sales % Group =
DIVIDE(
   SUM(Sales[Sales]),
   CALCULATE(

         Region[Country]
      )
   )
)
</pre>

IF(
   ISINSCOPE(Region[Region])

      CALCULATE(
         SUM(Sales[Sales]),
         REMOVEFILTERS(
            Region[Region],
            Region[Country]
         )
      )
   )
)
</pre>

## Data Analytics

Core components of analytics are divided into the following categories:

   * Descriptive - what has happened based on historical data. Key Performance Indicators (KPIs) such as return on investment (ROI) track performance toward key objectives.

   * Diagnostic - answers why events happened.  discover the cause of these events. why these events improved or became worse. Identify anomalies

   * Predictive - answers questions about what will happen in the future.  identify trends

   * Prescriptive - answer questions about which actions should be taken to achieve a goal or target. patterns in large datasets.

   * Cognitive help you learn what might happen if circumstances change, to determine how to handle these situations.
