## Building blocks

The basic building blocks in Power BI:

   * Visualizations – Visual representations of data, sometimes just called visuals
   * Datasets – Collections of data that Power BI uses to create visualizations
   * Reports – Collections of visuals from a dataset, spanning one or more pages
   * Dashboards – Single-page collections of visuals built from reports
   * Each app from the AppSource is a collection of ready-made visuals, pre-arranged in dashboards and reports.
   * The canvas is the area in the center of the Power BI service.
   * Tiles within Dashboard
   <br /><br />

Common data sources like Microsoft Excel files, databases, or Microsoft Azure data, 
real-time Azure Synapse Analytics tables that combine with other databases and real-time sources to build a moment-by-moment dataset.

Power BI can software services (aka SaaS providers or cloud services): 
 Salesforce, Facebook, Google Analytics, and more.

## Typical workflow

The most common flow of activity:

1. Bring <strong>data into Power BI Desktop</strong> and <strong>create a report</strong> (based on template?).
2. Publish to the Power BI service, where you can create new visualizations or build dashboards.
3. Share dashboards with others, especially people who are on the go.
4. View and interact with <strong>shared dashboards and reports</strong> in Power BI <strong>Mobile</strong> apps.

## DA-100 certification

Pay $165 to pass <a target="_blank" href="https://docs.microsoft.com/en-us/learn/certifications/exams/da-100">exam DA-100 "Analyzing Data with Microsoft Power BI"</a> to make you a <a target="_blank" href="https://docs.microsoft.com/en-us/learn/certifications/data-analyst-associate/">"Microsoft Certified: Data Analyst Associate"</a>. Threshold for passing:<br />
A minimum score of 70 percent on the overall exam.<br />
A minimum score of 35 percent on each exam domain:

* <a target="_blank" href="https://docs.microsoft.com/en-us/learn/paths/prepare-data-power-bi/">LEARN:</a> Prepare  data [for analysis] (20-25%)
* <a target="_blank" href="https://docs.microsoft.com/en-us/learn/paths/model-power-bi/">LEARN</a>: Model the data (25-30%)
* <a target="_blank" href="https://docs.microsoft.com/en-us/learn/paths/visualize-data-power-bi/">LEARN:</a>Visualize the data (20-25%)
* <a target="_blank" href="https://docs.microsoft.com/en-us/learn/paths/perform-analytics-power-bi/">LEARN</a>: Analyze the data (10-15%)
* <a target="_blank" href="https://docs.microsoft.com/en-us/learn/paths/manage-workspaces-datasets-power-bi/">LEARN: Manage workspaces</a>: Deploy and maintain deliverables (10-15%)

## Data Analytics

Core components of analytics are divided into the following categories:

   * Descriptive - what has happened based on historical data. Key Performance Indicators (KPIs) such as return on investment (ROI) track performance toward key objectives.

   * Diagnostic - answers why events happened.  discover the cause of these events. why these events improved or became worse. Identify anomalies

   * Predictive - answers questions about what will happen in the future.  identify trends

   * Prescriptive - answer questions about which actions should be taken to achieve a goal or target. patterns in large datasets.

   * Cognitive help you learn what might happen if circumstances change, to determine how to handle these situations.

<a target="_blank" href="https://docs.microsoft.com/en-us/learn/modules/data-analytics-microsoft/3-roles">Roles</a> and tasks:

   * Business analyst
   * Data analyst - <a target="_blank" href="https://docs.microsoft.com/en-us/learn/modules/data-analytics-microsoft/4-tasks">Tasks</a>: Prepare, Analyze, Model, Manage, Visualize
   * Data engineer
   * Data scientist
   * Database administrator
