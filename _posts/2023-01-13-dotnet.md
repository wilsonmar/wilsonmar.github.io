## All the pieces

Job descriptions for a "Microsoft full stack developer" mention dozens of technologies.
Here is the order I recommend:

1. .NET is the ecosystem Microsoft built around the architecture of ...
2. CLR (Common Language Runtime), which is equivalent to the JVM (Java Virtual Machine), where intermediate code that can be run on various machines (Linux, Mac, Windows) be generated by various programming languages

3. Nuget is the repository of .NET packages online (equivalent to NPM, Maven, PyPi, etc.)
4. <a target="_blank" href="https://learn.microsoft.com/en-us/aspnet/core/?view=aspnetcore-7.0">ASP.NET Core</a> is for web development using the MVC (Model-View-Controller) programming pattern (equivalent to Node.Js)
5. ".NET Framework" only runs on Windows, so now deprecated
6. ".NET Core" is cross-platform (on Linux, Mac, Windows). Last release December 3, 2019 now superceded by .NET 5 and onward.
7. .NET Core SDK (Software Development Kit) are libraries referenced by programming languages
8. .NET Standard library is the shared set of libraries

9. Visual Studio Code is the free text editor (with lots of add-ons)
10. Visual Studio 2022 for Windows is the licen$ed editor with powerful debugging features (runs only on Windows machines)
11. C# (C-sharp) is the programming language
12. F# (F-sharp) is the functional programming language
13. PowerShell CLI (equivalent to Bash Shell on Linux)
  
14. .NET MAUI to build apps running on iPhone and Android mobile devices
15. Razor provides templating in code (equivalent to handle bars)
16. Blazor to build user interface components run in internet browsers WebAssembly for near-native performance [<a target="_blank" href="https://www.youtube.com/watch?v=QKr1HPq6YlI">course</a>]
17. Silverlight deprecated?
18. EF Core (Enterprise Framework)
19. SignalR to code real-time RPC (Remote Procedure Calls) using HTTP/2 protocol
20. Xamarin/Mono is .NET for mobile. It's being replaced by .NET MAUI.
21. UWP (Universal Windows Platform) is used to build desktop apps that run on Windows, Mac, and Linux
22. gRPC in ASP.NET Core to develop contract-first, high-performance web services
23. <a target="_blank" href="https://learn.microsoft.com/en-us/dotnet/architecture/dapr-for-net-developers/">Dapr (Distributed Application Runtime)</a> apps are cloud-native event-driven, portable runtimes that can run within Kubernetes on most clouds

24. MS-SQL is the database from Microsoft that runs on many platforms
25. Azure Cosmos DB runs on the Azure cloud
26. LINQ to query and manipulate data within databases (add-on to SQL language)
<br /><br />

Additionally, there are DevOps and "Backing" utilities created and managed by a platform team for developers to consume:

* IAM for MFA and SSO
* Secrets management (HashiCorp Vault)
* Network management (Load Balancers, Gateways)
* Git and GitHub
* CI/CD
* Code vulnerability scanners (SonarQube, etc.)
  
* Log accumulation, visualization of trends, and alerting
* Backup and restore
* Kubernetes and Istio Service Mesh
* Health checks
* Monitoring and Observability
* etc.
