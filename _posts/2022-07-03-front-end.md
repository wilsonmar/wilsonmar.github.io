## Microsoft's MAUI

In July 2021, Microsoft <a target="_blank" href="https://visualstudiomagazine.com/articles/2021/07/27/net-maui-kits.aspx">announced a replacement for Xamarin.Forms Toolkits with New .NET MAUI Alternatives</a> at https://dot.net/maui. <a target="_blank" href="https://github.com/dotnet/maui/tree/main/src/Essentials">MAUI = (Multi-platform App UI)</a> -- offered with .NET 6 (due November 2021) -- is a cross-platform framework for using C#, XAML, and PowerShell to develop <strong>MacOS, Tizen (like Linux)</strong> and Windows desktop apps in addition as well as iOS and Android mobile apps, for a write-once run-anywhere developer experience, but with the option to access native aspects of each environment.

No Linux platform support!

* <a target="_blank" href="https://github.com/dotnet/maui/tree/main/src/Essentials">Xamarin.Essentials</a> provides developers with cross-platform APIs for mobile apps.
* Xamarin Community Toolkit includes commonly found behaviors, converters, effects.
* MVVM utilities and controls including the CameraView, AvatarView, and TabView. 
<br /><br />

Like Xamarin, MAUI <a target="_blank" href="https://docs.microsoft.com/en-us/visualstudio/mac/supported-versions-net?WT.mc_id=dotnet-35129-website&view=vsmac-2022">requires a paid Visual Studio IDE license</a>. Such a requirement may be a hurdle for some developers.The Pro edition IDE is <a target="_blank" href="https://visualstudio.microsoft.com/vs/pricing/">priced at</a> $45/month, but allows a $50 USD credit on Azure.
The Enterprise edition is $250/month, but allows a $150 USD credit on Azure and enables Test Plan access on Azure DevOps.

PROTIP: The new Visual Studio for Mac uses a different .NET 6.0 SDK installer than the Visual Studio 2022 for Mac (v17.0 latest preview).
