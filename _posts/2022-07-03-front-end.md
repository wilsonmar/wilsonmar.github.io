## Microsoft's MAUI

<a target="_blank" href="https://visualstudiomagazine.com/articles/2021/07/27/net-maui-kits.aspx">In July 2021, Microsoft announced</a>
<a target="_blank" href="https://github.com/dotnet/maui/tree/main/src/Essentials">MAUI = (Multi-platform App UI)</a> with .NET 6. 
MAUI -- at https://dot.net/maui -- is a replacement for Xamarin.Forms Toolkits </a>. MAUI is a cross-platform framework for using C#, XAML, and PowerShell to develop <strong>MacOS, <a target="_blank" href="https://www.tizen.org/">Tizen</a></strong> and Windows desktop apps in addition as well as iOS and Android mobile apps, for a write-once run-anywhere developer experience, but with the option to access native aspects of each environment.

Although supported by the Linux Foundation, MAUI <a target="_blank" href="https://developer.samsung.com/smarttv/develop/tizen-net-tv.html">except</a> for the <a target="_blank" href="https://developer.samsung.com/smarttv/develop/tizen-net-tv.html">.NET TV framework</a> runs on <a target="_blank" href="https://developer.samsung.com/smarttv/develop">Samsung smart TVs</a> and Google WearOS wearables. [<a target="_blank" href="https://www.wikiwand.com/en/Tizen">Wikipedia</a>]

## Photino

Photino is offered at <a target="_blank" href="https://www.tryphotino.io/">tryphotino.io</a> by CODE Magazine with the help of the open-source community.
at <a target="_blank" href="https://github.com/tryphotino">Github.com/tryphotino</a>.

Photino uses Web UI technology to build native, cross-platform desktop apps that "are lighter than light". Light weight because the browser control is usually already installed, so we only have to install the wrapper (can be packaged).
If .NET 5 is already installed on the OS, it's really fast.

Photino.Native is compiled for each platform and distributed as a
NuGet package at https://www.nuget.org/packages?q=photino

Photino.Native is a C++ (and Objective C) wrapper around the OS’s
built-in Chromium or WebKit-based browser control that opens a
native window on the desktop with the browser control in it.

   * On Windows this means the WebView2 control – a browser control for native
applications based on Chromium Edge.
   * On Mac, this means WKWebView – a WebKit browser control for native
applications based on Safari.
   * On Linux, this means WebKitGTK+2 – a browser control for native applications
based on WebKit directly.
