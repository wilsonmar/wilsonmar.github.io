The objective of this document is to, with minimal fuss, install Kali Linux and its thousands of associated tools running within an AWS cloud VPC for tunneling into. Same for Azure and GCP cloud.

To establish a playground for both offensive and defensive <strong>Penetration Testing</strong>, Security Auditing, Computer Forensics, and Reverse Engineering.


## Install on your laptop Docker?

Kali Linux is a set of security tools that hackers use is a security risk. 
So you don't want to install it on your laptop for hackers to hack your machine.

So install enough utilities on your laptop for use to install Kali in a cloud
for you to access from your laptop.


## Install in the cloud

Running Kali in a cloud enables you to bring it up, use it, and tear it down.

No worries about getting hacked because it's separate from the machine you use to access your bank accounts and other personal information.

For quick repeatability, to simplify, and for auditing before resources are created, we use Terraform to create the cloud infrastructure.

There are several ways to install Kali Linux to SSH into within a cloud:

   A - Docker container images<br />
   B - In AWS, use the "Kali Linux" AMI image for EC2 made for your region from the AWS Marketplace AMI Catalog<br />
   C - Use Packer utility to create a custom AMI image in AWS 
   <br /><br />

### Select & Install AWS AMI image

1. Create a new secret key pair for each new EC2 instance.

1. Setup AWS secrets, access keys, and region <strong>us-west-2</strong</strong>

1. Install Terraform and other utilities on your laptop

1. Clone the starter Terraform module created by <a target="_blank" href="https://www.linkedin.com/in/robertpeteuil/">Robert Peteuil</a>

   See https://askubuntu.com/questions/53582/how-do-i-know-what-ubuntu-ami-to-launch-on-ec2

### Connect to Kali server

1. Connect to the AWS instance using the key pair created in the previous step.

   <pre>kali@kali:~$ <strong>ssh -i "keys.pem" kali@ip</strong>
   </pre>

1. After connecting, change the password using

   <pre><strong>sudo passwd kali
   </strong></pre>

1. To use a GUI, use one of two options for SSH forwarding. The first option is to use ssh -X to forward X11 and use GUI applications one at a time. The second option is to use Windows RDP to forward the traffic over SSH. To set up RDP, we will run the RDP with the <tt>Xfce</tt> script used for WSL. After this, we can tunnel with ssh -N -L 3390:127.0.0.1:3390 and connect using any remote desktop client to 127.0.0.1:3390.

1. Install Kali's many <strong>Metapackages</strong>

   <pre><strong>sudo apt update && sudo apt install -y kali-linux-headless</strong></pre>

   
   ### NVIDIA drivers

1. TO use GPUs for cracking through the AWS instance, install the NVIDIA packages after everything is up-to-date and the proper Linux headers are installed: https://www.kali.org/docs/general-use/install-nvidia-drivers-on-kali-linux/

   <pre>sudo apt update
sudo apt full-upgrade -y
sudo apt install -y linux-headers-5.7.0-kali3-cloud-amd64
sudo reboot -f
   </pre>

   To reconnect to the session:

   <pre>sudo apt install -y nvidia-driver nvidia-cuda-toolkit
   sudo reboot -f
   </pre>
