The jq utility is <a target="_blank" href="https://thoughtbot.com/blog/jq-is-sed-for-json">like the sed Linux utility</a>, but for JSON. They both reformat and transform text.

The "j" in the jq program name means it queries a JSON-formatted file to produce <strong>filtered</strong> output.

On a Mac, command <tt>brew install jq</tt> reveals that the utility has a dependency of the <a target="_blank" href="https://en.wikipedia.org/wiki/Oniguruma">oniguruma regular expression handler</a> and is from Stephen Dolan's <a target="_blank" href="https://stedolan.github.io/jq/">stedolan.github.io/jq</a>


## Install

On Mac:

   <ul><tt>brew install jq</tt></ul>

On Ubuntu:

   <ul><tt>apt-get install jq</tt></ul>

On Windows Git Bash, download <strong>jq-win64.exe</strong> from <a target="_blank" href="https://github.com/stedolan/jq/releases">github.com/stedolan/jq/releases</a> into a bin folder in the PATH, and specify the program in commands:

   <ul>
   <tt>echo '{"foo": 0}' | ./jq-win64.exe .</tt>

   <pre>{
  "foo": 0
}</pre>
   </ul>

## How to jq

<a target="_blank" href="https://stedolan.github.io/jq/manual/">https://stedolan.github.io/jq/manual</a>
presents a large (and potentially confusing) list of options.

Here's an abridged version with examples explained step-by-step.

1. The ipinfo.io website returns the IP address and its metadata: location Lattitude and Longitude, postal (ZIP code), Unix time zone, carrier (org), State of the Union (region), etc.

   <tt>curl ipinfo.io
   </tt>

   yields:

   <pre>
{
  "ip": "184.153.97.231",
  "hostname": "cpe-184-153-97-231.nyc.res.rr.com",
  "city": "Woodside",
  "region": "New York",
  "country": "US",
  "loc": "40.7454,-73.9054",
  "org": "AS12271 Charter Communications Inc",
  "postal": "11377",
  "timezone": "America/New_York",
  "readme": "https://ipinfo.io/missingauth"
}
   </pre>

   NOTE: All JSON responses begin and end with curly braces between { and }.

1. A dot represents the entire input, but formatted with indents:

   <tt>curl ipinfo.io | jq '.'</tt>

1. <tt>.[]</tt> returns each element of the array, one at a time,

   <tt>curl ipinfo.io | jq '.[]'</tt>


1. If you only want one city name (with no JSON braces or quote marks):

   <tt>curl ipinfo.io | jq -r .city
   </tt>

   NOTE: jq receives a file <strong>piped in</strong>, as specified by the pipe character |.

1. To return the response in a variable within a Bash script:

   <tt>CITY=$( curl ipinfo.io | jq -r .city )
   </tt>
