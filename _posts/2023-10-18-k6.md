## Run Simplest Script Locally

PROTIP: Ideally, an app development project's github repo would contain a folder in the same repo as the app code (such as "k6") so that changes in app code have corresponding test code.

1. In Terminal, cd to the folder, for example:

   <pre><strong>cd ~/Documents/GitHub/</strong></pre>

1. Create a folder by cloning from my repo containing :

   <pre><strong>git clone git@github.com:wilsonmar/oss-perf.git --depth 1
   cd oss-perf/k6
   </strong></pre>

1. View the <tt>k6-test-ping.js</tt> which "pings" or lands on the test.k6.io web server:

   <pre>import http from 'k6/http';
import { sleep } from 'k6';
export const options = {
  vus: 10,
  duration: '30s',
};
export default function () {
    http.get('http://test.k6.io');
    sleep(1);
}
   </pre>

   The <tt>k6/http</tt> specifies a <a target="_blank" href="https://k6.io/docs/using-k6/modules/#built-in-modules">built-in module</a> imported to make HTTP requests.
  
1. View the report.

1. Run from within Visual Studio Code, press command+shift+p to get the Command Palette, then type <tt>k6</tt> to get the menu:

   <pre>>k6: Run current file
   k6: Run current file in k6 cloud
   k6: Open Settings
   </pre>

   Alternatively, in Terminal, cd to the folder, for example:

   <pre><strong>time k6 run k6-test-ping.js</strong></pre>

   NOTE: The <tt>time</tt> command is an optional Unix command that measures the time it takes to run the k6 command.
