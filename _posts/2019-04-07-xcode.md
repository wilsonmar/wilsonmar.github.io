## The utilities needed

This tutorial describes how to install several utilities needed by developers running HomeBrew, Python, and other programs on Macs:
   * <a href="#gcc">gcc</a> - the C language compiler
   * cc
   * <a target="_blank" href="https://wilsonmar.github.io/make/">make</a>
   * <a target="_blank" href="https://wilsonmar.github.io/make/">git</a>
   <br /><br />

{% include whatever.html %}

<a name="2installers"></a>

## TD;LR Overlapping installers!

<a href="#UtilitiesNeeded">Utilities needed (above)</a> can be installed two different ways into two different folders:

   * If utilities were installed using <strong>CommandLineTools (CLI)</strong>:<br /><br /><tt>/Library/Developer/CommandLineTools</tt>  

   * If utilities were installed using <strong>Apple's Xcode IDE (GUI)</strong>:<br /><br /><tt>$HOME/Applications/Xcode.app</tt> 

> <strong>Choose one</strong>. Developers using NOT developing apps to run on an <a href="#ApplePlatforms">Apple platform</a> (macOS, iOS, etc.) don't need the XCode IDE GUI, so can <a href="#InstallCU">install just the CommandLineTools</a>.


<a name="InstallCU"></a>

## Which one are you using?

Apple is kind enough to provide a command that either installs CLI tools or show the path of the CLI installed.

1. Open a Terminal by pressing command+spacebar and typing "T" to select <strong>Terminal</strong>.
1. In a Terminal Shell Window, type any of the <a href="#UtilitiesNeeded">commands above</a> or this command:

   <pre><strong>xcode-select --install</strong></pre>

   Alternately, <a target="_blank" href="https://gist.github.com/brysgo/9007731">this shell script</a> which makes use of Apple's osascript:

   <pre>xcode-select --install > /dev/null 2>&1
if [ 0 == $? ]; then
    sleep 1
    osascript <<EOD
tell application "System Events"
    tell process "Install Command Line Developer Tools"
        keystroke return
        click button "Agree" of window "License Agreement"
    end tell
end tell
EOD
else
    echo "Command Line Developer Tools are already installed!"
fi
   </pre>

1. If already installed you would see <a href="#2installers">one of the two paths above</a>.

   If NOT installed, you'll see:

   <pre>xcode-select: note: No developer tools were found, requesting install.
If developer tools are located at a non-default location on disk, 
use `sudo xcode-select --switch path/to/Xcode.app` to specify 
the Xcode that you wish to use for command line developer tools,
and cancel the installation dialog.
See `man xcode-select` for more details.
   </pre>

1. Press command+Tab as many times as needed to select the utility icon. This dialog should appear:

   <a target="_blank" href="https://res.cloudinary.com/dcajqrroq/image/upload/v1706813577/xcode-req-dev-tools-870x296_grnkui.png"><img alt="xcode-req-dev-tools-870x296.png" src="https://res.cloudinary.com/dcajqrroq/image/upload/v1706813577/xcode-req-dev-tools-870x296_grnkui.png"></a>

1. Click "Install" for "Downloading".

1. If "Stop" is clicked, the install would resume where it was interrupted.

1. Click "Done" when "The software was installed." appears.

1. Repeat the <a href="#InstallCU">command above</a> 

   * If XCode CLI was installed, you should see:<br />

   <ul><pre>/Library/Developer/CommandLineTools</pre></ul>

   * If XCode.app was installed, you should instead see:

   <ul><pre>/Applications/Xcode.app/Contents/Developer</pre></ul>


   <a name="gcc"></a>

   ### Path of gcc

1. To identify the <strong>path</strong> to one of the <a href="#UtilitiesNeeded">utilities listed above</a>, such as <strong>gcc</strong>, use the <tt>xcrun</tt> utility that comes with macOS:

   <pre><strong>xcrun --find gcc</strong></pre>

   If Command Line Utilities are installed, the response would be:

   <tt><strong>/Library/Developer/CommandLineTools/usr/bin/gcc</strong></tt>

   If Xcode.app is installed, the response would be:

   <tt><strong>/Applications/Xcode.app/Contents/Developer/usr/bin/gcc</strong></tt>

   If neither is installed:
    
   <pre>xcrun: error: active developer path ("/Library/Developer/CommandLineTools") does not exist
Use `sudo Xcode-select --switch path/to/Xcode.app` to specify the Xcode that you wish to use for command line developer tools, or use `Xcode-select --install` to install the standalone command line developer tools.
See `man Xcode-select` for more details.
   </pre>

   The same for <tt>make</tt> and other utilities.

   Again, if "Command not found" appears, either <a href="#InstallCU">install CommandLineTools</a> or install XCode.app, then return here.

   Let's see what is in those folders:

   <pre><strong>ls -al /Library/Developer/CommandLineTools

   ## Specifying the XCode utility to use

   PROTIP: Xcode.app cannot be installed if Command Utilities has already been installed. So the installation program needs to first check whether XCode.app or CommandLineTools is installed.

   Choose which one you want to use:

1. Reset:

   <pre><strong>sudo xcode-select -r</strong></pre>

   The command provides no response.

* To specify the use of Xcode.app (IDE):

   <pre><strong>sudo xcode-select --switch /Applications/Xcode.app
   </strong></pre>

   Enter Password for the sudo.

* To specify the use of CommandLineTools:

   <pre><strong>sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
   </strong></pre>
   
   Enter Password.

<a name="UnInstallCU"></a>

## UnInstall Command Line Tools

   PROTIP: Deleting the "Command Line Tools" folder is also how to uninstall and reinstall.

1. Open a new window or tab shell in your Terminal app.

1. Go to the parent folder where Command Line Tools is installed:

   <pre><strong>cd /Library/Developer/CommandLineTools
   </strong></pre>

1. Remove all files in that folder, provide a password for elevated permissions to get all the files:

   <pre><strong>sudo rm -rf /Library/Developer/CommandLineTools
   </strong></pre>
 
   Input your password when prompted.

   The response is a lot of files removed (to the Trash).

   Now <a href="#InstallCU">install CommandLineTools</a> (or <a href="#InstallIDE">install the full Xcode IDE</a>).

   CAUTION: On a Mac M1 (Apple Silicon chip, macOS 12.0 Monterey), after installed the Command Line Tools then uninstalled them by deleting /Library/Developer/CommandLineTools and running sudo xcode-select -r, I was still getting updates to the tools in System Preferences > Software Update.

   The files below are protected by SIP: to delete them, I had to disable SIP first (ie disable SIP, delete the files, re-enable SIP).

   Indeed, the receipts are at /Library/Apple/System/Library/Receipts, in the form of files:
   * com.apple.pkg.CLTools_Executables.{bom,plist}
   * com.apple.pkg.CLTools_SDK_macOS*.{bom,plist}
   * com.apple.pkg.CLTools_macOS_SDK.{bom,plist}


   ### Software Update

   To get to "Software Update":

1. Click the Apple icon or press command+, (comma).
1. Click Settings. Click General. Click Software Update.

   <a target="_blank" href="https://github.com/timsutton/osx-vm-templates/blob/ce8df8a7468faa7c5312444ece1b977c1b2f77a4/scripts/xcode-cli-tools.sh">A shell script</a> uses these commands to not require manual clicking on the dialog that pops up (below):

   <pre><strong>#!/bin/sh
# Create placeholder file checked by CLI updates' .dist code in Apple's SUS catalog:
touch /tmp/.com.apple.dt.CommandLineTools.installondemand.in-progress;
# Find the CLI Tools update:
PROD=$(softwareupdate -l |
  grep "\*.*Command Line" |
  head -n 1 | awk -F"*" '{print $2}' |
  sed -e 's/^ *//' |
  tr -d '\n')
# Unless "No new software available.", install it:
softwareupdate -i "$PROD" -v;
   </strong></pre>

   ![Xcode-select-prompt-444x148](https://user-images.githubusercontent.com/300046/83383584-acf52d80-a3a2-11ea-9316-6ac91ccb99a4.jpg)

   <a name="InstallPopUp"></a>

1. If you see this pop up, manually click "Install", "Agree", then "Install". It says "Finding software", then "Downloading software". Finally, "Updates Available" appears.

   CAUTION: The large number of files means this can a long time. It took 13 minutes on my 10mbps line.

1. When you see "The software was installed.", click "Done" to dismiss the pop-up.

   <a name="SetLicense"></a>

   ### Set license

1. If you try to confirm the <a href="#versions">versions installed</a>, you'll see:

   <tt>You have not agreed to the Xcode license agreements. You must agree to both license agreements below in order to use Xcode.
   &nbsp;
   Press the 'return' key to view the license agreements at '/Applications/Xcode.app/Contents/Resources/en.lproj/License.rtf'
   </tt>

1. Press q, then type "agree".
1. Press spacebar several times until it says:

   <tt>Agreeing to the Xcode/iOS license requires admin privileges, please run “sudo xcodebuild -license” and then retry this command.</tt>

1. Run the command suggested to set Apple's licensing agreement bit:

   <pre><strong>sudo xcodebuild -license
   </strong></pre>

   Enter your password for the sudo.

1. Confirm the <a href="#versions">versions installed</a>.

<a name="XCode.app"></a>

## About Xcode.app

Xcode is Apple's free IDE developers use to create custom programs for an <a href="#ApplePlatforms">Apple platform</a>. 

There is no Windows PC version of XCode. XCode only works on macOS. 
This limitation has served to increase the need for MacBooks.

Increasingly, Machine Learning developers are using Apple's Swift language.

1. Visit Apple's Xcode marketing page at

   <a target="_blank" href="https://developer.apple.com/Xcode/">https://developer.apple.com/Xcode</a>

   Xcode "includes everything you need to create amazing apps for all Apple platforms. Now Xcode and Instruments look great in the new Dark Mode on macOS Mojave. The source code editor lets you transform or refactor code more easily, see source control changes alongside the related line, and quickly get details on upstream code differences. You can build your own instrument with custom visualization and data analysis. Swift compiles software more quickly, helps you deliver faster apps, and generates even smaller binaries. Test suites complete many times faster, working with a team is simpler and more secure, and much more.".
   
   PROTIP: Newer versions of Xcode installer also installs a Git client.

   <a name="XcodeSize"></a>

   ### How big is the XCode installer?

1. To see how big the XCode installer is, visit Apple's fancy "downloads" web page:

   <a target="_blank" href="https://developer.apple.com/download/applications/">https://developer.apple.com/download/applications</a>

   Scroll down to a version that doesn't say "beta".

   <a target="_blank" href="https://res.cloudinary.com/dcajqrroq/image/upload/v1686944857/xcode-1431-792x314_gj9gx4.png"><img alt="xcode-1431-792x314.png" src="https://res.cloudinary.com/dcajqrroq/image/upload/v1686944857/xcode-1431-792x314_gj9gx4.png"></a>

   Notice the size, such as "(7.01 GB)".

   Because XCode.app is several Gigabytes large, developers who do not create Apple programs can save disk space and time to install it by not installing it. 

   Also, installer size is also why Xcode does not come with macOS.

   Since the Apple Store only handles individual .app files, other mechanisms are needed to install additional programs needed as a pre-requisite by Homebrew, Python, and other development programs.

1. Make sure you have at least <strong>13GB free</strong> on your hard-drive before attempting installation.

   1. Click the Apple icon to select "About this Mac".
   2. Click "Storage" tab.
   <br /><br />

There are other IDEs used by developers (such as Visual Studio, Eclipse, IntelliJ, PyCharm, etc.).
