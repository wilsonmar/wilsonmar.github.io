<a target="_blank" href="https://wilsonmar.github.io/xcode">This tutorial</a> describes the installation and usage of Apple’s XCode set of utilities for macOS developers.

XCode is Apple's free app for developing custom programs for all Apple devices (macOS, iPhone, iPad, Apple Watch). Increasingly, Machine Learning developers are using the Swift language.

Since the Apple Store only handles individual .app files, other mechanisms are needed to install additional programs needed as a pre-requisite by Homebrew, Python, and other development programs.

BTW Xcode only works on macOS. There is no Windows PC version.

## About XCode

PROTIP: Skip Apple's websites and App. <a href="#2installers">Click here for install instructions</a>.

Otherwise, read on for a run-around.

0. Use an internet browser to XCode's marketing page at:

   <a target="_blank" href="https://developer.apple.com/xcode/">
   https://developer.apple.com/xcode</a>

   Xcode "includes everything you need to create amazing apps for all Apple platforms. Now Xcode and Instruments look great in the new Dark Mode on macOS Mojave. The source code editor lets you transform or refactor code more easily, see source control changes alongside the related line, and quickly get details on upstream code differences. You can build your own instrument with custom visualization and data analysis. Swift compiles software more quickly, helps you deliver faster apps, and generates even smaller binaries. Test suites complete many times faster, working with a team is simpler and more secure, and much more.".
   
   BTW the "Apple platforms" include MacOS, iPhone, iPad, Apple TV, and Apple Watch.

XCode does not come with macOS because of <a href="#XCodeSize">its large size</a> 
and because many users of macOS don't need it to do software development.

Developers who use another IDE (such as Visual Studio, Eclipse, etc.) would only need to install XCode's <strong>command line utilities</strong> for the <strong>GCC compiler</strong> Python needs to build code.

PROTIP: Newer versions of XCode installer also installs a Git client.

## Overlapping installers

Imagine a Venn diagram of overlapping circles:

   1. The XCode IDE, which can be installed on a <a href="#XCodeInstall">Terminal command line interface (CLI)</a> or <a href="#AppStoreInstall">downloaded as a package from the App Store</a>.

   Either way, XCode contains:

   2. <strong>Command Line Utilities</strong> which can be installed separately on a Terminal command line session.
   <br /><br />

> PROTIP: XCode cannot be installed if Command Utilities has already been installed.
However, you can select:

   <pre><strong>sudo xcode-select --switch <em>path/to/Xcode.app</em>
   </strong></pre>

So choose which one you want installed.


<a name="versions"></a>

## What Has Been Installed?

1. In a Terminal window, find out what has been installed: 

   <pre><strong>xcode-select -p
   </strong></pre>

   That's the same command as:

   <pre><strong>xcode-select --print-path</strong></pre>

   If the xcode-select command is not found, choose to <strong>either</strong> <a href="#InstallCU">install Command Line Tools</a> 
   or install the full XCode IDE.

   You have Command Line Tools installed and not the full XCode if you see the path <a href="#InstallCU">where CommandLineTools are installed</a>:

   <pre>/Library/Developer/CommandLineTools</pre>




   If all you need is Command Line Tools, you're good to go.

   Alternately, if the full XCode was installed, you would instead see:

   <pre>/Applications/Xcode.app/Contents/Developer
   </pre>

   <pre>/Applications/Xcode8.3.3/Xcode.app/Contents/Developer</pre>

1. Get a list of its folders if XCode IDE was installed:

   <pre><strong>ls /Applications/Xcode.app</strong></pre>

   The response would be:

   <pre>Applications Library      Makefiles    Platforms    Toolchains   Tools        usr</pre>

   <pre><strong>xcode-select --install</strong></pre>


   ### Delete first

1. PROTIP: If you want the full XCode IDE when you have the Command Line Tools installed, first <a href="#UnInstallCU">uninstall Command Line Tools</a>, 
   then <a href="#XCodeInstall">install the full XCode IDE</a>.


   ## More version information

   <a name="xcodebuild"></a>

   ## XCode Version

1. From within a Terminal, type:

   <pre><strong>/usr/bin/xcodebuild -version
   </strong></pre>

   If Command Line Tools was installed, you would see:
   
   <pre>xcode-select: error: tool 'xcodebuild' requires Xcode, but active developer directory '/Library/Developer/CommandLineTools' is a command line tools instance</pre>

   If XCode is installed, you would get a version code that should match up with the Build Number on the Apple web page:

   <pre>Xcode 10.2.1
Build version 10E1001
   </pre>

1. For a more precise version number and other info (macOS Mavericks version and up):

   <pre><strong>pkgutil --pkg-info=com.apple.pkg.CLTools_Executables
   </strong></pre>

   A sample response, at time of writing:

   <pre>package-id: com.apple.pkg.CLTools_Executables
version: 11.5.0.0.1.1588476445
volume: /
location: /
install-time: 1590584803
groups: com.apple.FindSystemFiles.pkg-group
   </pre>

   The previous command was constructed based on a search of tools package names:

   <pre>pkgutil --pkgs | grep -i tools
   </pre>

   The response:

   <pre>com.apple.pkg.CLTools_Executables
com.apple.pkg.CLTools_SDK_macOS1015
com.apple.pkg.CLTools_SDK_macOS1014
com.apple.pkg.CLTools_macOS_SDK
   </pre>

1. Get the version of GCC installed:

   <pre><strong>gcc --version</strong></pre>

   If XCode was installed, you would see (at time of writing):

   <pre>Configured with: --prefix=/Applications/Xcode.app/Contents/Developer/usr --with-gxx-include-dir=/Applications/Xcode.app/Contents/Developer/Platforms/MacOSX.platform/Developer/SDKs/MacOSX10.14.sdk/usr/include/c++/4.2.1

Thread model: posix
InstalledDir: /Applications/Xcode.app/Contents/Developer/Toolchains/XcodeDefault.xctoolchain/usr/bin
   </pre>

   If Command Line Utilities is installed, you would see (at time of writing):

   <pre>Configured with: --prefix=/Library/Developer/CommandLineTools/usr --with-gxx-include-dir=/Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/usr/include/c++/4.2.1
Apple clang version 11.0.3 (clang-1103.0.32.62)
Target: x86_64-apple-darwin19.4.0

InstalledDir: /Library/Developer/CommandLineTools/usr/bin
   </pre>

1. Identify the path where the <strong>make</strong> utility Java uses:

   <pre><strong>xcrun --find gcc</strong></pre>

   a. If XCode is installed, the response is:

   <pre>/Applications/Xcode.app/Contents/Developer/usr/bin/make</pre>

   b. If Command Line Utilities is installed, the response is:

   <pre>/Library/Developer/CommandLineTools/usr/bin/gcc</pre>

   c. If no XCode is installed:
    
   <pre>xcrun: error: active developer path ("/Library/Developer/CommandLineTools") does not exist
Use `sudo xcode-select --switch path/to/Xcode.app` to specify the Xcode that you wish to use for command line developer tools, or use `xcode-select --install` to install the standalone command line developer tools.
See `man xcode-select` for more details.
   </pre>

   <a name="Swift"></a>

   ### Swift version

1. Get the version of the Swift program used to develop iOS mobile apps:

   <pre><strong>swift -version</strong></pre>

   Sample response at time of this writing:

   <pre>Apple Swift version 5.2.4 (swiftlang-1103.0.32.9 clang-1103.0.32.53)
Target: x86_64-apple-darwin19.4.0</pre>

   The above appears regardless of whether Command Line Utilities or XCode is installed.

   From here, uninstall and install Command Line Tools or <a href="#XCodeInstall">install the full XCode IDE</a>.


   <a name="UnInstallCU"></a>

   ## UnInstall Command Line Tools

   PROTIP: This is also how you <strong>upgrade Command Line Tools</strong>.

1. Go to the parent folder where Command Line Tools is installed:

   <pre><strong>cd /Library/Developer 
   </strong></pre>

1. Get a list of its folders:

   <pre><strong>ls CommandLineTools
   </strong></pre>

   If Command Line Tools were installed, the response would be :
   
   <pre>Library	SDKs	usr</pre>

1. Remove all files in that folder, which requires a password for elevated permissions to get all the files:

   <pre><strong>sudo rm -rf /Library/Developer/CommandLineTools
   </strong></pre>

   The response is a lot of files removed (to the Trash).

   Now you can choose to <strong>either</strong> <a href="#InstallCU">install Command Line Tools</a> 
   or install the full XCode IDE.


   <a name="InstallCU"></a>

   ## Install Command Line Utilities only

   See https://developer.apple.com/library/archive/technotes/tn2339/_index.html and <a target="_blank" href="http://osxdaily.com/2014/02/12/install-command-line-tools-mac-os-x/">http://osxdaily.com/2014/02/12/install-command-line-tools-mac-os-x</a>

1. To install the whole XCode IDE:

   <pre><strong>xcode-select --install</strong></pre>

   You should see this pop up:
   
   ![xcode-select-prompt-444x148](https://user-images.githubusercontent.com/300046/83383584-acf52d80-a3a2-11ea-9316-6ac91ccb99a4.jpg)

1. Manually click "Install", "Agree", then "Install" to the "Updates Available" pop-up.

   NOTE: The download takes 13 minutes on a 10mbps line.

1. When you see "The software was installed.", click "Done" to dismiss the pop-up.

<a name="XCodeInstall"></a>

## XCode IDE install from Terminal

PROTIP: Either way, if you have Command Utilities already installed, you must first delete it.

1. In Finder, look for <strong>XCode.app</strong> in the <tt>/Applications</tt> folder.

1. Alternately, on the Touchpad pinch 4 fingers together to click the <strong>App Store</strong>. 
   Type enough of "XCode" to filter out others. 
   Then double-click on the <strong>XCode.app</strong> to install it.

1. To view the version, cursor to the top of the screen and click the program name next to the Apple icon to select "About XCode":

   ![xcode about 271x48](https://cloud.githubusercontent.com/assets/300046/21987451/dc44154a-dbc0-11e6-90b6-4dce91b8c5d2.png)



   ### Install full XCode IDE

(This is to read the XCode IDE's ratings)

0. Make sure you have at least <strong>10GB free</strong> on your hard-drive before attempting installation.

0. In an internet browser, get to the "Mac App Store Preview" for Xcode at<br /><a target="_blank" href="https://apps.apple.com/us/app/xcode/id497799835?mt=12">https://apps.apple.com/us/app/xcode/id497799835?mt=12</a>

   <img width="683" alt="xcode-web-preview.png" src="https://user-images.githubusercontent.com/300046/95787611-1e20e780-0c97-11eb-97b7-a4a6a70619be.png">

0. Click <strong>View in Mac App Store</strong>, then "Open App Store.app" in the pop-up.
0. Provide your Apple ID and password. Get one if you don't already have one.

   Don't click the blue "OPEN" icon at the upper-right to open the app if the app was installed.

   PROTIP: DO NOT install a beta version of Xcode.

0. Scroll down to click <strong> See All</strong> on the right edge.
0. Click "Sort by Most Recent".
0. Read through the Ratings to decide for yourself.
0. Click the red dot at the upper-right to dismiss the dialog.


   ### Close all other applications open.

1. Press command+Tab until the application you want to close next is highlighted.
1. Press command+Q to close it.
1. If a file needs to be saved, do that.


### A) Initial install from Terminal CLI

1. Open a Terminal.app console window at any directory to install -all the latest XCode from Apple:

   <pre><strong>softwareupdate --install -a
   </strong></pre>

   The response on Catalina version of macOS:

   <pre>Software Update Tool
&nbsp;
Finding available software
&nbsp;
Downloaded macOS Catalina 10.15.5 Update
Installing macOS Catalina 10.15.5 Update
Done.
To install these updates, your computer must shut down. Your computer will automatically start up to finish installation.
Installation will not complete successfully if you choose to restart your computer instead of shutting down.
Please call halt(8) or select Shut Down from the Apple menu. To automate the shutdown process with softwareupdate(8), use --restart.
   </pre>

1. Click the Apple icon at the upper-right corner and select "Shut Down...".


   ### After starting again

2. Set Apple's licensing agreement bit:

   <pre><strong>sudo xcodebuild -license
   </strong></pre>

3. Manually agree to the terms.

4. Get the version number of the new version.

0. Go through Apple's location verification if prompted.

<a name="XCodeUpgrade"></a>

### XCode IDE Upgrade

Over time, Apple updates XCode and its command line utilities.

1. Click the Apple icon, then click <strong>System Preferences</strong>. Here is an example notification:

   ![xcode-cli-update-436x98-4795](https://user-images.githubusercontent.com/300046/56460275-7e162680-635d-11e9-8d3c-0bb89457dcd8.jpg)

2. Search for "Software Updates" or click the icon.
2. Click "Update Now" if that appears. (but first do a backup.)
3. Click "Agree" to the EULA.
4. When done, view the <a href="#versions">version numbers installed</a>.
