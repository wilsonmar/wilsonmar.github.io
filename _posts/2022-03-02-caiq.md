## One Q&A to Answer Them All

Cloud providers make use of the <a target="_blank" href="https://cloudsecurityalliance.org/download/artifacts/star-level-1-security-questionnaire-caiq-v4/">Cloud Security Alliance (CSA) Consensus Assessment Initiative Questionnaire (CAIQ) v4</a>.

The spreadsheet of answers from various cloud providers incorporate <a target="_blank" href="https://cloudsecurityalliance.org/research/cloud-controls-matrix/">CSA's  Cloud Controls Matrix (CCM)</a> of each control expressed as a <strong>task</strong>.

Answer spreadsheets from notable cloud providers:

   * <a target="_blank" href="https://downloads.esri.com/resources/enterprisegis/AGOL_CSA_CAIQ.pdf">PDF: ESRI's answers</a> references both SOC2, <a target="_blank" href="https://www.iso.org/isoiec-27001-information-security.html">ISO 27001:2018</a>, and FedRamp 880-53.
   * <a target="_blank" href="https://d1.awsstatic.com/whitepapers/compliance/CSA_Consensus_Assessments_Initiative_Questionnaire.pdf">PDF: Amazon's answers</a>
   * https://cloudsecurityalliance.org/star/registry/microsoft/
   * https://www.oracle.com/a/ocom/docs/oci-corporate-caiq.pdf
   * https://services.google.com/fh/files/misc/sep_2021_caiq_self_assessment.pdf
   * https://cloudsecurityalliance.org/star/registry/atlassian/services/jira-and-confluence-cloud/
   <br /><br />

<a target="_blank" href="https://cloudsecurityalliance.org/blog/2020/04/04/why-use-the-caiq-for-vendor-analysis-vs-other-questionnaires/">Why CAIQ for vendor analysis vs. other questionnaires?</a> 
The CCM aligns itself with over 40 of the leading standards and regulations, it basically eliminates the need for any other questionnaire.

<a name="Titles"></a>

## Control ID Groupings

Each question is associate with a <strong>title</strong>, which can be shared with other questions.

For example, "A&A-01.1" and  "A&A-01.2" share the title "Audit and Assurance Policy and Procedures" and the Control ID "A&A-01".

Each Control ID is associated with a title, CCM control, and a <a href="#Metrics">Metric</a>.


### Ref. to ISO & FedRamp

Each title/CCM control in <a target="_blank" href="https://downloads.esri.com/resources/enterprisegis/AGOL_CSA_CAIQ.pdf">PDF: ESRI's answers</a> references both <a target="_blank" href="https://www.iso.org/isoiec-27001-information-security.html">ISO 27001:2018</a>, and FedRamp 880-53.

<a name="Metrics"></a>

### Security Metrics

CSA has mapped to the CCM v4 <a target="_blank" href="https://cloudsecurityalliance.org/artifacts/the-continuous-audit-metrics-catalog/">PDF: <strong>34 security metrics</strong></a> to support <strong>Continuous Audit</strong>. These metrics aim to support internal CSP governance, risk, and compliance (GRC) activities and provide a helpful baseline for service-level agreement transparency. 

For example, Metric "UEM-09-M1" is associated with CCMv4 Control ID "UEM-09" with this Description:

<ul>
This metric measures the percentage of instances which are an running anti-malware/virus service.
</ul>

Each metric can be related to several controls.<br />
For example, "UEM-09-M1" is related to "TVM-02, DCS-05, DCS-06, DSP-01".
UEM-09-M1 depends on an asset database such as from DCS-06.

### A&A = Audit Assurance & Compliance<br /><br />
