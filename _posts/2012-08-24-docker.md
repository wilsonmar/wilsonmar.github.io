## Docker glossary:

- <strong>image</strong>: a read-only template with instructions for creating a Docker container

- <strong>container</strong>: a runnable instance of an image. You can create, start, stop, move, or delete a container using the Docker API or CLI

- <strong>volume</strong>: persists data generated by and used by Docker containers

- <strong>dangling</strong>: unused image or volume

- <strong>network</strong>: connects Docker containers and services

## Enterprise features

> PROTIP: Most tutorials don't cover Enterprise features Docker's licensed <a target="_blank" href="https://www.docker.com/products/docker-enterprise">Enterprise Edition (EE)</a> documented at <a target="_blank" href="https://docs.docker.com/ee/">https://docs.docker.com/ee</a>. Nevertheless, the DCA exam includes questions about additional enterprise features for businesses wanting a secure and supported container platform for their datacenter:

   * Version Packs in Desktop Enterprise to keep the client in sync (v 3.0 vs. 2.1)
   * <tt>docker app</tt> packaging command to install clients in swarm or kubernetes according to the vendor-neutral <a target="_blank" href="https://cnab.io/">"Cloud Native Application Bundle" (CNAB) spec</a> at <a target="_blank" href="https://github.com/deislabs/cnab-spec">https://github.com/deislabs/cnab-spec</a>
   * Vulnerability scans 
   * Notary
   * <tt>docker cluster</tt> command to create, ls, backup, restore clusters as code on AWS, Azure, and VSphere
   * Docker Kubernetes Service support of all Docker Enterprise features such as<br /><tt>docker stack deploy</tt>
   * <tt>docker context</tt>
   * <tt>docker template</tt>
   * <tt>docker buildx</tt>
   * <tt>docker assemble</tt>
