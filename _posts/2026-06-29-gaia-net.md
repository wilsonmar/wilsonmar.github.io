When Gaia Nodes connect to a Gaia Domain, it adds reasoning capabilities.

Nodes can be <a target="_blank" href="https://docs.gaianet.ai/getting-started/quick-start/">installed on macOS, Linux, Azure/AWS</a>:

1. Make a folder to hold
   ```
   mkdir -p gaianetper; cd gaianet
   ```
1. Download
   ```
   curl -sSfL 'https://github.com/GaiaNet-AI/gaianet-node/releases/latest/download/install.sh' | bash
   ```
1. Check both shell and running process:
   ```
   if [[ $SHELL == *"zsh"* ]] || [[ $(ps -p $$ -o comm=) == *"zsh"* ]]; then
      source ~/.zshrc"
   else
      source ~/.bash_profile"
   fi
   ```
1. Initialize <tt>$HOME/gaianet/config.json</tt>
   ```
   gaianet init
   ```

1. Start node:
   ```
   gaianet start
   ```
1. wasmedge is the process running in the background:
   ```
   ps -al
   ```
