This is a hands-on succinct introduction to using Katalon's comprehensive toolset for both exploratory and scripted (automated) testing. Use it to test Web and mobile UI (Katalium). It tests both SOAP and RESTful APIs. 
It enables BDD Cucumber to express test scenario in natural language. 

Katalon leverages open-source browser control engines Selenium for web UI and Appium for mobile UI.

<a target="_blank" href="https://www.katalon.com/about-us/">
Their top people</a> (with an address in Atlanta, GA) make money by charging <a target="_blank" href="https://www.katalon.com/training/?utm_source=docs-navigation-bar">$8,000 for training</a>, <a target="_blank" href="https://www.katalon.com/support-service-options/">$5,000/year for support</a>, and licenses for enterprise features to run CI/CD at scale.

It's Katalon Studio (KS) is an IDE that's free of charge with no limitations on quota but no support after online activation.

   * <a target="_blank" href="https://forum.katalon.com/discussions">https://forum.katalon.com/discussions</a>

   * <a target="_blank" href="https://docs.katalon.com/katalon-studio/docs/index.html">https://docs.katalon.com/katalon-studio/docs/index.html</a>


Katalon Studio Enterprise (KSE) is a paid IDE with exclusive features, basic support, all Katalon plugins, and options to activate offline.

Katalon Runtime Engine (RE): is a paid CLI console to execute "TestOps" in CI/CD infrastructures or via the command-line interface with options to activate offline. Compatible with KS and KSE. All console executions require the Runtime Engine.

## Studio Installation

Available on macOS, Windows, and Linux.

1. Create an account by signing up at:

   <a target="_blank" href="https://www.katalon.com/sign-up/">
   https://www.katalon.com/sign-up</a>

2. PROTIP: To make it easier to upgrade, instead of clicking "Download" on the website, install the GUI app using a package manager.

   On MacOS, after installing Homebrew:

   <tt><strong>brew cask install katalon-studio
   </strong></tt>
