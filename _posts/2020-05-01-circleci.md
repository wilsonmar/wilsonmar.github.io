This tutorial is a hands-on tour to introduce the "CircleCI" tool that automates Continuous Integration.

CircleCI says it runs 30M+ jobs per month. 

Although their headquarters is in San Francicso, 30% of their 250+ employees work remotely as a global team.

Who gave them money?

## Competitors

CircleCI is a "pure play" strategy to focus only on CI/CD while its cloud services competitors (AWS, Azure, GCP) provide a full vertical stack that includes SVS, security scanning, etc.

Industry analyst Forrester in their Q3 2019 report of CI/CD vendors gave CircleCI the lowest rating (2.30 of 5.0) among all alternatives.
CircleCI's "Conguration and analytics" score is the third lowest.
Customer references told Forrester they’d like to see a more customizable dashboard with more-useful analytics. 

![circleci-forrester-2019-Q3-566x623](https://user-images.githubusercontent.com/300046/80894360-966e9000-8c97-11ea-8484-6584420f0971.png)

However, CircleCI got "5.0" (along with Microsoft) for "Enterprise support" and "Commercial model" (along with AWS CodeBuild, Microsoft Azure DevOps, and Google Cloud Build).

CircleCI’s <a name="#Orbs">"orbs"</a> technology allows customers to  integrate and maintain third-party applications for more-resilient build pipelines. 

"CircleCI lacks a hybrid orchestration model [?], an option that an increasing number of enterprise customers tell Forrester they’re interested in."

The CircleCI server can be hosted on-premise, in a private cloud, or in their public SaaS cloud. <a target="_blank" href="https://circleci.com/pricing/server/">On-prem costs $8,400/year</a>.

Being able to run its server in a macOS VM is a unique offering (for mobile iOS builds), but <a target="_blank" href="https://circleci.com/pricing/#">Circle requires a paid plan of $30+ a month</a>. Free builds are only for Linux and Windows VMs.

In Settings > Plan Usage of 2,500 units per week are spent on Compute Minutes and Compute Credits.

## GUI Getting Started

Pipelines are a full set of configuration you run when you trigger work on your projects in CircleCI. Pipelines are the envelope around your workflows, which coordinate jobs.

Pipelines on CircleCI normally are kicked off automatically by a Git Hook when a commit occurs on GitHub or Atlassian BitBucket VCS.

Pipelines can be kicked off using CircleCI's GUI or CLI.

## CLI Getting Started

This section describes how a shell script can access CircleCI from a Terminal or cron job. We'll run a sample shell script several times.

1. Navigate to a Terminal.

1. Triple-click the line below to capture it in your invisible Clipboard:

   <pre><strong>??? sample.sh -s -L -v -f "hello-world.config.yml"</strong></pre>

   <tt>-s</tt> specifies that the script load <tt>~/.secrets.sh</tt> which specifies values for system variables.

   <tt>-L</tt> specifies using CircleCI, creating a <tt>.circleci</tt> folder on you $HOME folder and installing the CLI program if it's not already installed.

   <tt>-v</tt> specifies verbose output.

   <tt>-f "hello-world.config.yml"</tt> specifies the file to be renamed and copied into $HOME/.circleci/config.yml for CircleCI to use.

1. Switch to the Terminal and press command+V to run the script. 

   Among the last lines of the response is this line, but with your User name instead of the example name:

   <tt>Please edit file /user/wilson_mar/.secrets.sh and run again ..."</tt>


   ## Get CircleCI API Token

1. Switch to the Finder app and navigate to your User $HOME folder.

   PROTIP: The home folder is used to hold a secrets file because there is little chance that it will be pushed to a public GitHub/VCS.

1. Open the <tt>secrets.sh</tt> file to use your favorite Text Editor to open it. For example, VSCode:

   <pre><strong>code ~/.secrets.sh</strong></pre>

1. Add this line if it's not already there, so that you are ready to paste a value to substitute:

   <tt>CIRCLECI_API_TOKEN="xxx"</tt>

1. Switch to a browser at the <a target="_blank" href="https://circleci.com/dashboard">CircleCI.com Dashboard</a>. Login.

   NOTE: There are <a target="_blank" href="https://circleci.com/docs/2.0/managing-api-tokens/">different steps to get a Project Token</a>.

1. For a Personal Token, click your user icon at the upper-right to select "User settings", "Personal API Tokens", "Create New Token".

   Alternately, for a Project Token, click the gear icon next to your project’s settings. In the Permissions section, click on API Permissions. Click the Create Token button. Choose a scope from the dropdown menu.

1. Click in the "Token name" field and type a unique name for the token and press Add.
1. Click "Copy" to put the value in your invisible Clipboard. Close.

1. Switch to the Text Editor, double-click the value to select all of it, and press command+V to paste the token:

   <tt>CIRCLECI_API_TOKEN="a2c738f8cbafbfbe80aaf1ada3b9bbc625dc42a1"</tt>

1. Save the file.

   ## Orbs in workflows

   <pre># Use the latest 2.1 version of CircleCI pipeline process engine. See: https://circleci.com/docs/2.0/configuration-reference
version: 2.1
# Use a package of configuration called an orb.
orbs:
  # Declare a dependency on the welcome-orb
  welcome: circleci/welcome-orb@0.4.1
# Orchestrate or schedule a set of jobs
workflows:
  # Name the workflow "welcome"
  welcome:
    # Run the welcome/run job in its own container
    jobs:
      - welcome/run
   </pre>




   that specifies use of a Docker image from the circleci account on DockerHub:

   <pre>version: 2
jobs:
  build:
    docker:
      - image: circleci/python:3.6.2-stretch-browsers
    steps:
      - checkout
      - run: pip install -r requirements/dev.txt
   </pre>

   "docker" is the executor.

   The Docker image contains a Python interpreter that can process the Python requirements/dev.text file which specifies what Python modules to install.
