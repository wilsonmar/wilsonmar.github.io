Most web developers I know work on macOS or Linux laptops rather than Windows.

This has been an issue for traditional vendors offering Windows-only clients such as VuGen ( a part of the LoadRunner offering from MicroFocus, formerly Mercury and HP).

Vendors such as <a target="_blank" href="https://flood.io/">Tricentis Flood.io</a> now provide cloud-based solutions partly because every laptop can have an internet browser.

{% include whatever.html %}


## TL;DR Summary

In 2018 MicroFocus delivered a way to do performance testing on <strong>macOS</strong> (and elsewhere) using cross-platform tools such as Node, Ruby, and Python.

TruWeb is not a client program like VuGen, but CLI programs and a JavaScript SDK installed as plugins in text editors (VS Code, Atom.io, JetBrains WebStorm, Eclipse).

1. From the <a target="_blank" href="https://marketplace.microfocus.com/appdelivery/content/truweb">MicroFocus Marketplace</a>, the macOS download is currently 54MB. There are also installers for Linux and Windows. After un-zip are two files:

   * ProxyRecorder_2019.2.4.tar.gz un-tars to folder "truWebProxyRecorder" (containingaddonScripts in Python)
   * TruWeb_2019.2.4.tar.gz un-tars to folder "TruWeb"
   <br /><br />

1. After un-tar, PROTIP: Create a TruWeb folder and move those folders there, then trash the zip and tar.gz files to save disk space.

   Looking in the bin folder, we see that what makes TruWeb multi-platform is its use of Node.

   Runs can be invoked from within the editor <a target="_blank" href="https://admhelp.microfocus.com/truweb/en/latest/help/Content/TruWeb/TW-run-scripts.htm">calling the TruWeb program</a> after you run:

   * Run-time settings are specified in the <tt>rts.yml</tt>.
   * Arguments are in a separate <tt>user_args.json</tt> file.
   * Parameters are specified in the <tt>parameters.yml</tt> file.
   <br /><br />

   If you prefer a GUI for such files, the SDK is also within VuGen for Windows and StormRunner online.

   TruWeb scripts are written in <strong>JavaScript</strong>. So NodeJs modules such as <a target="_blank" href="https://lodash.com/">lodash</a> can be loaded to make it easier to work with arrays, numbers, objects, strings, etc.
   Virtual Table Server functions are available. Several examples come with TruWeb.

   QUESTION: What about Rendezvous points and IP address spoofing?

   TruWeb scripts are generated from HAR files captured using the 3rd-party Fiddler, WireShark, or the <strong>OfflineGenerator</strong> program. PROTIP: Being an industry-standard, HAR files can be viewed by various utilities not from Micro Focus.

   The <a target="_blank" href="https://admhelp.microfocus.com/truweb/en/latest/help/Content/TruWeb/TW-offline-generator.htm">OfflineGenerator</a> is controlled by specifications in files <tt>generator_config.yml</tt> and <tt>correlation_rules.yml</tt>. Instead of "correlations", TruWeb now has <a target="_blank" href="https://admhelp.microfocus.com/truweb/en/latest/help/Content/TruWeb/TW-JS-SDK.htm#Extracto">"Extractors"</a>.

   To capture HAR files, the provided (Ruby-based) <a target="_blank" href="https://admhelp.microfocus.com/truweb/en/latest/help/Content/TruWeb/TW-recording.htm">proxy program provided</a> uses default port 8156, as specified in the config.yml.

   But you'll have to get and <a target="_blank" href="https://admhelp.microfocus.com/truweb/en/latest/help/Content/TruWeb/TW-proxy_recorder.htm">install CA certificates</a>.

   Use the <a target="_blank" href="https://admhelp.microfocus.com/truweb/en/latest/help/Content/TruWeb/TW-masking.htm">>TruWebUtils program</a> to encrypt plain text.

1. Download the helper files for your favorite text editor (Visual Studio Code).

1. PROTIP: Trash the zip and tar.gz files to save disk space.
1. Create a TruWeb folder and move expanded folders there.
1. Define a <strong>TRUWEB_PATH</strong> environment variable containing the location where TruWeb binaries are installed (for example, for Windows: C:\TruWeb). This allows integration of the standalone version of TruWeb into other tools (for example, Atom.io).

   In MacOS, add in <strong>.bash_profile</strong> an export of the environment variable.

   On Linux, define the environment variable in the .rc file relevant to your distribution home directory.
