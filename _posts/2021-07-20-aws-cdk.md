AWS defines their CDK (Cloud Development Kit) as:

> "A multi-language software development framework for <strong>modeling</strong> cloud infrastructure as reusable components"

Programmatic coding enable <strong>reusable</strong>class libraries (templates) which define entire sets of services using a single line:<a target="_blank" href="https://www.youtube.com/watch?v=nlb8yo7SZ2I&t=1m54s">*</a>

   <pre>#!/usr/bin/env node
import 'source-map-support/register';
import * as cdk from '@aws-cdk/core';
import { TheBigFan Stack} from '../lib/the-big-fan-stack';
&nbsp;
const app = new cdk.App();
new TheBigFanStack(app, 'TheBigFanStack');
   </pre>

The above code references "<strong>Constructs</strong>" which bundles infrastructure into reusable components deployed by a <a target="_blank" href="https://docs.aws.amazon.com/cdk/latest/guide/stacks.html"><strong>stack</strong></a> which "synth" out templates in CloudFormation or Terraform.
