AWS defines their CDK (Cloud Development Kit) as:

> "A multi-language software development framework for <strong>modeling</strong> cloud infrastructure as reusable components"

Programmatic coding enable <strong>reusable</strong>class libraries (templates) which define entire sets of services using a single line:<a target="_blank" href="https://www.youtube.com/watch?v=nlb8yo7SZ2I&t=1m54s">*</a>

   <pre>#!/usr/bin/env node
import 'source-map-support/register';
import * as cdk from '@aws-cdk/core';
import { TheBigFan Stack} from '../lib/the-big-fan-stack';
&nbsp;
const app = new cdk.App();
new TheBigFanStack(app, 'TheBigFanStack');
   </pre>

The above code references "<strong>Constructs</strong>" which bundles infrastructure into reusable components deployed by a <a target="_blank" href="https://docs.aws.amazon.com/cdk/latest/guide/stacks.html"><strong>stack</strong></a> which "synth" out templates in CloudFormation or Terraform.

AWS and open-source contributors develop <strong>construct libraries</strong> for each of its many services (RDS, CloudFront, Kinesis, etc.). Reinvent 2019: How to make contributions ? https://www.youtube.com/watch?v=9As_ZIjUGmY

Template code contains:

   * if/else and for loops (control logic)
   * autocomplete
   * in-line documentation
   * compile-time warnings
   * modeling of cross-account and cross-region pipeline configurations

   ### Node version alignment

1. If you get an error such as this when you run:

   <pre>/usr/local/Cellar/aws-cdk/1.114.0/libexec/lib/node_modules/aws-cdk/node_modules/yargs-parser/build/index.cjs:1007
        throw Error(`yargs parser supports a minimum Node.js version of ${minNodeVersion}. Read our version support policy: https://github.com/yargs/yargs-parser#supported-nodejs-versions`);
              ^
Error: yargs parser supports a minimum Node.js version of 10. Read our version support policy: https://github.com/yargs/yargs-parser#supported-nodejs-versions
   </pre>

1. What version of NodeJs do you have installed?

   <tt><strong>node -v</strong></tt>

   If you have a version less that (10), such as "v9.11.1", upgrade Node to the version specified (v10).

1. To enable multiple versions of Node to be installed simultaneously, install NVM:

   <pre><strong>brew install nvm</strong></pre>

1. Identify an LTS version to install:

   <pre><strong>nvm ls</strong></pre>

   <pre>

## NPM Code

1. In the https://docs.aws.amazon.com/cdk/latest/guide/cli.html install a fall-back global version:

   <tt><strong>npm install -g aws-cdk             # install latest version</strong></tt>

   PROTIP: Be prepared to work with multiple versions of the AWS CDK installed.
   Install a matching version of the AWS CDK Toolkit in individual CDK projects (omitting -g from the npm install command).
