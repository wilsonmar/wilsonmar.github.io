<a id="AutoInstall"></a>

This is a hands-on tutorial for the fastest way to configure everything on your Mac for software development, specific to what you and your team want installed, so you can do pair programming without distraction.

To take with a new laptop:

1. Obtain a macOS laptop (from Apple, Amazon, or 2nd-hand). Unbox it. Order <a target="_blank" href="https://wilsonmar.github.io/apple-macbook-hardware/">Apple hardware accessories</a>. Arrange it all on your desk for convenient access.
   
2. Get familiar using the <a target="_blank" href="https://wilsonmar.github.io/apple-mac-osx-keyboard/">keyboard</a> and Trackpad.

3. <a target="_blank" href="https://wilsonmar.github.io/apple-mac-osx-backup/">Save baseline data to Time Machine</a> (before making changes), as part of <a target="_blank" href="https://wilsonmar.github.io/backup/">a full backup and restore strategy</a>

4. Open Safari (the Mac's built-in internet browser) to review the script code at:

   <a target="_blank" href="https://github.com/wilsonmar/mac-setup/blob/master/mac-setup.zsh">https://github.com/wilsonmar/mac-setup/blob/master/mac-setup.zsh</a>

   Notice "zsh" is used instead of "bash" to accomodate Apple's new defaults.

   The idea here is to have one script that installs everythnig needed: from XCode to Brew to Python.

   Sections in the script are sequentially numbered. Run-time flags specify actions the script takes.

   Coding in the script is explained in <a target="_blank" href="https://wilsonmar.github.io/shell-scripts">https://wilsonmar.github.io/shell-scripts</a>

   Here I aimed to use shell scripting techniques that are the easiest to understand rather than the most "elegant" and esoteric tricks that some others use to prove how superior they are. But if you disagree with something, please let me know. I welcome your suggestions.

5. Open a Terminal by pressing command+spacebar, then type enough of <strong>Terminal.app</strong> to select it.

6. Commands make use of the <tt>curl</tt> utility to download. So make you don't get any error about that:

   <pre><strong>curl --version</strong></pre>

   You should see several lines such as:

   <pre>curl 7.79.1 (x86_64-apple-darwin13.4.0) libcurl/7.79.1 OpenSSL/1.1.1l zlib/1.2.11 libssh2/1.10.0 nghttp2/1.43.0
Release-Date: 2021-09-22
Protocols: dict file ftp ftps gopher gophers http https imap imaps mqtt pop3 pop3s rtsp scp sftp smb smbs smtp smtps telnet tftp 
Features: alt-svc AsynchDNS GSS-API HSTS HTTP2 HTTPS-proxy IPv6 Kerberos Largefile libz NTLM NTLM_WB SPNEGO SSL TLS-SRP UnixSockets
   </pre>

7. Use your mouse to triple-click the command below to highlight it, then press command+C to copy it to your Clipboard:

   <pre><strong>zsh -c "$(curl -fsSL https://raw.githubusercontent.com/wilsonmar/mac-setup/main/mac-setup.zsh)" -v
   </strong></pre>

   <tt>-v</tt> specifies verbose log output.

8. Press command+V to paste the command from your Clipboard. 

9. Press Return/Enter on your keyboard to begin execution. The script should return a list of sample parameters because the command requests no features except

9. Expand the width of your Terminal window by dragging the right edge so you see any more line wrapping.

9. Paste the command again to add more parameters to additional command executions. See <a target="_blank" href="https://wilsonmar.github.io/mac-setup/#customize-mac-setup-specifications-to-your-liking">"Customize mac-setup specifications to your liking"</a>

   <tt>-I</tt> specifies install of base utilities and app most popular among developers using macOS.

   <tt>-go</tt> specifies install of Go language.
   
   etc.

9. Again press Return to start the script running.

   The script creates a <tt>~/Projects/mac-setup</tt> folder on your machine and downloads the <tt>mac-setup.zsh</tt> script file into it.

   If a utility program is not installed, the script installs it.

   We created the script to automatically take care of workarounds to issues.

9. If you (and your team) want a different set of configurations (utilities and apps to install), save the script and 

9. Alternately, edit the configuration file and run <a href="Ansible">Ansible</a>.

## Dotfiles #

<a target="_blank" href="http://dotfiles.github.io/">
GitHub's Dotfiles</a> manage files containing preferences for command-line programs.

For example, the configuration file for Zsh is .zshrc.
The SSH configuration folder is .ssh.
And on.

Such files have a dot because they are hidden.

Famous collections of dotfiles from:

* https://github.com/holman/dotfiles from Zach Holman
* Matthias Bynens
* Paul Irish
* https://github.com/mattstauffer/ohmyzsh-dotfiles

Features added by dotfiles:

   * Color grep output
   * Boost ls commands
   * Adding plugins to vim

### Symlinks #

Symlinks to files allow you to git pull and watch your dotfiles instantly update.

One
stores .ssh-config file in his Dropbox folder which he symlinks:

   <pre>
   touch ~/Dropbox/.ssh-config
   ln -s ~/Dropbox/.ssh-config ~/.ssh/config
   </pre>

The .ssh-config file contains:

<pre>
# My Awesome Web Site
Host awesome
    Hostname 141.141.141.141
    User me_duh
    IdentityFile=/Users/me/.ssh/id_for_awesome_site.rsa
</pre>

The above enables him to invoke:

   <pre><strong>
   ssh awesome
   </strong></pre>

   No more remembering ip addresses, fumbling with command line switches for multiple SSH IDs, or even remembering your ssh usernames.


   * https://mattstauffer.co/blog/setting-up-a-new-os-x-development-machine-part-3-dotfiles-rc-files-and-ssh-config

To get rid of the GarageBand music program, which comes with Apple MacOS:

0. In a Terminal, go to where Apple stores its default apps at:

   <pre>
   cd "/Library/Application Support/GarageBand/"
   </pre>

   The quotes are needed because there is a space in the folder name.

0. See how much disk space it takes.

   <pre>
   ls -al
   </pre>

   <pre>

   <pre>
