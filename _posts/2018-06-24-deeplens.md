On Jan 31, 2023 AWS announced retirement of Deeplens.
See https://docs.aws.amazon.com/deeplens/latest/dg/deeplens-end-of-life.html

<hr />

This article provides a step-by-step tutorial with commentary on configuring the AWS Deeplens wi-fi camera and its local computer and big AWS AI cloud.

AI engineers have not needed DeepLens before because they have been uploading media to servers.

What DeepLens provides is <strong>real-time processing</strong> of <strong>scenes</strong> (visual imagery and sounds from the built-in 2D microphone array) on the little computer and in Amazon's cloud. 

One can <a target="_blank" href="https://www.tensorflow.org/mobile/ios_build">run TensorFlow on iOS</a> and Android smart phones because smart phones today have similar hardware to DeepLens, which has an Intel Atom chip with 8GB RAM. DeepLens is a way for Amazon to monitize the AI hype.

DeepLens is a step up from the Raspberry Pi Zero board and cardboard case of the <a target="_blank" href="https://www.target.com/p/google-vision-kit-aiy/-/A-53417081">$90</a> <a target="_blank" href="https://www.amazon.com/Google-AIY-Vision-Kit-V1-1/dp/B078YJ64WR/">Google Vision Kit AIY</a> that recognize objects. See MyTGTtech at 877-698-4883 (7am-11pm CST).

Within the DeepLens white box, <strong>AWS Greengrass Core</strong> runs AWS Lambda functions that invoke <strong>neural network models</strong> trained by Machine Learning software.

Outputs from DeepLens:

   * The "Device stream" is passed through the device without processing.

   * The "Project stream" output is the result of processing video frames through AWS Lambda functions on-board, referencing a "CNN deep learning inference model". A "project" are speech-enabled (using Amazon Polly API service).

  To restore a DeepLens device to factory settings, 
   wiping out all data:

1. Press the on/off button at the front of the DeepLens device

2. Select "Boot From File", USB VOLUME, EFI, BOOT, BOOTx64.EFI

   If errors occur, repeat from first step. A result.log will be generated on the USB drive. 
5. Wait for the flashing process to complete (~ 6min). After that, your device will automatically reboot.

6. Your device is now restored, so remove the USB flash drive.

## Greengrass 

https://aws.amazon.com/greengrass/
https://console.aws.amazon.com/iot/home#/greengrassIntro
Greengrass Core runs on top of IoT devices (such as Raspberry Pi) running Amazon FreeRTOS or have the AWS IoT Device SDK installed.
Greengrass Core enables Lambda functions to run locally on IoT devices.

Greengrass runs local machine learning inference using models built and trained by AWS Sagemaker in the cloud.
See https://aws.amazon.com/greengrass/ml/

Greengrass keep device data encrypted and synchronized with the AWS cloud via MQTT protocol.
Greengrass communicates securely with other devices within a <strong>Greengrass Group</strong>.
Greengrass authenticates and encrypts data using the security and access management capabilities of AWS IoT Core. 
Greengrass can filter device data it transmits back to the cloud.

A Greengrass Group coordinates communication among up to 200 devices installed with Greengrass Core.

## MNNet

AWS DeepLens comes pre-installed with the <a target="_blank" href="https://github.com/apache/incubator-mxnet">Apache MXNet framework</a> and <a href="#Gluon">Gluon</a> interface of models in Jupyter Python3 notebooks.

This is largely because (unlike TensorFlow) MXNet can be used with more languages: Python, R, Perl, Matlab, Scala, C++. MXNet itself is written in C++.

MXNet can use 32 or 16 bit  weights and activations for smaller and faster models﻿.

However, AWS developers can run any deep learning framework, including TensorFlow and Caffe.

### AWS Gluon

Gluon (pronounced like "Glue-on") at <a target="_blank" href="https://gluon.mxnet.io/">https://gluon.mxnet.io</a> is an open source interface to get around the "black box" of training deep learning models semantically.
Gluon uses imperative programming aka "define by run". "You can use the Python debugger. You can stop the training process. You have full control over the training loop"
<a target="_blank" href="https://www.youtube.com/watch?v=Vw-bX1RRZGQ&t=5m2s">*</a> 

You can get started with a wide range of computer vision tutorials for Gluon, including full notebooks ready to run on SageMaker.

Deploy the model to your DeepLens, where the model optimizer will automatically optimize it for the best performance on the device.
