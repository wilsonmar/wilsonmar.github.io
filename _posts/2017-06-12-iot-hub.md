This article provides additional detail from <a target="_blank" href="https://wilsonmar.github.io/azure-iot/">Microsoft's Azure IoT</a>.

Here is a hands-on step-by-step guided tour to Microsoft's Azure IoT Hub, which runs in Microsoft's Azure cloud (as a SaaS offering). Azure is one of [several IoT clouds I've looked at](/iot-clouds/).

What's different about this article is I have created a <a href="#InstallScript">Bash <strong>install.sh</strong> shell script</a> you can run to automate installation on your MacOS. I am testing the script on Windows 10 under Git Bash and various Linux distros.
