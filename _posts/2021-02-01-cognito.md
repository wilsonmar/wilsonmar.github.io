This article describes how to use AWS Cognito through API Gateway 
to authorize users via a Python Lambda program.

## The sequence:

1. User clicks on static web page
2. Request login
3. Python Lambda program trigger
4. API Gateway 
5. AWS Cognito (or Auth0)
