### Pillars of the framework:

* <a href="#Ops">Operational Excellence</a> = Operations processes that keep a system running in production (organization structure, monitoring)
* <a href="#Sec">Security</a> = Protecting applications and data from threats
* <a href="#Reliability">Reliability</a> = The ability of a system to recover from failures and continue to function
* <a href="#Perf">Performance Efficiency</a> = The ability of a system to adapt to changes in load
* <a href="#Cost">Cost Optimization</a> = The ability to achieve business outcomes at the lowest price point - Managing costs to maximize the value delivered

## Security

The broad security areas:

* Identity and access management
* Infrastructure protection
* Data protection: sovereignty and encryption
* Incidence response
* Application security
* Security resources
<br /><br />

Design principles for security in the cloud:

* Implement a strong identity foundation
* Enable traceability
* Apply security at all layers
* Automate security best practices
* Protect data in transit and at rest
* Keep people away from data
* Prepare for security events
