At its developer conference on June 4, 2019, Apple buried the lead, which is that beginning with the Catalina version of macOS, Z shell is replacing Bash as the default shell.

See <a target="_blank" href="https://support.apple.com/en-us/HT208050">https://support.apple.com/en-us/HT208050</a>

Why Apple didn't just upgrade the current version of Bash to the current version 4, like other Linux distros?

Maybe it's because Apple wants to get back further to its FreeBSD roots?

<a target="_blank" href="https://mjtsai.com/blog/2019/06/04/macos-10-15-switches-from-bash-to-zsh/">
"All of this probably motivated by a desire to get away from GPL to MIT."</a>
based on <a target="_blank" href="http://meta.ath0.com/2012/02/05/apples-great-gpl-purge/">these statistics</a>.

## Why not Fish?

And why they didn't go with Fish, another alternative shell.



## About Z shell

Zshell is so old, it's <a target="_blank" href="https://sourceforge.net/p/zsh/code/ci/master/tree/">repository is still on Sourceforge</a> since its initial release in 1990.

https://www.wikiwand.com/en/Z_shell
says "Zsh is an extended Bourne shell with a large number of improvements, including some features of Bash, ksh, and tcsh."

Zsh also comes with an auto-update tool that makes it easier to keep installed plug-ins and themes updated. 

User experience advantages<a target="_blank" href="https://www.howtogeek.com/362409/what-is-zsh-and-why-should-you-use-it-instead-of-bash/">*</a>:

* Automatic cd: Just type the name of the directory

* Recursive path expansion: For example “/u/lo/b” expands to “/usr/local/bin”

* Spelling correction and approximate completion: If you make a minor mistake typing a directory name, ZSH will fix it for you

For Windows users:
https://www.howtogeek.com/258518/how-to-use-zsh-or-another-shell-in-windows-10/
