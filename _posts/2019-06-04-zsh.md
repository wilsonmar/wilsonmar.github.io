## News

At its developer conference on June 4, 2019, Apple stated that, beginning with the <a target="_blank" href="https://wilsonmar.github.io/apple-mac-osx-versions">Catalina version of macOS</a>, Z shell would replace Bash as the default shell.

BTW Shells are command line interface (CLI) that allows users to interact with the computer’s operating system by typing rather than moving a mouse on a GUI (Graphical User Interface).

<a name="Which"></a>

## It's already in there

It may surprise some that Apple has been delivering Z shell with macOS.

   PROTIP: MacOS defines the prompt display using the <strong>PS1</strong> system environment variable.

1. Identify the version installed:

   <pre><strong>zsh --version</strong></pre>

   The response (at time of writing):

   <pre>zsh 5.7.1 (x86_64-apple-darwin18.2.0)</pre>

   PROTIP: Zshell is so old, it's <a target="_blank" href="https://sourceforge.net/p/zsh/code/ci/master/tree/">repository is still on Sourceforge</a> since its initial release in 1990.

1. If you type in the command:

   <pre><strong>zsh</strong></pre>

   The response is a mess because zsh doesn't get prompt specifiers for Bash :

   <pre>\n  \w\[\033[33m\] $(parse_git_branch)\[\033[00m\]\n$</pre>

   `\n  ` add a blank line and indents. For easier readability.

   `\n` positions the cursor always on the same spot at the left of the screen so I don't have to search for it.

1. To flip back to Bash shell:

   <pre><strong>sh</strong></pre>

   PROTIP: Control the look of the prompt in Bash by setting the PROMPT_COMMAND variable to one or more of the special characters will customize it for you.



## Why the disruption?


Why Apple didn't just upgrade the current version of Bash to the current version 4, like other Linux distros?

Maybe it's because Apple wants to get back further to its FreeBSD roots?

<a target="_blank" href="https://mjtsai.com/blog/2019/06/04/macos-10-15-switches-from-bash-to-zsh/">
"All of this probably motivated by a desire to get away from GPL to MIT."</a>
based on <a target="_blank" href="http://meta.ath0.com/2012/02/05/apples-great-gpl-purge/">these statistics</a>.

<a target="_blank" href="https://www.theverge.com/2019/6/4/18651872/apple-macos-catalina-zsh-bash-shell-replacement-features">The Verge</a> notes that "Apple is stuck using version 3.2 of bash that has been licensed under GPLv2, as newer versions are licensed under GPLv3. Apple has kept clear of using GPLv3 packages in macOS as the license is generally more restrictive to companies like Apple that sign their own code and it includes explicit patent grants, too."


## The cost of change

> The big issue of concern is compatibility with other Linux distributions.
A further shift to MacOS's FreeBSD roots would add "cognitive overload".
because the vast majority of other CLI ecosystems remain on Bash.
Constantly thinking about whether one needs to use Z shell or Bash shell disrupts the "muscle memory" of developers, 
and thus reduce productivity.

Cloud shells on cloud vendors use Bash
   * Azure Cloud Shell https://shell.azure.com/
   * Google
   * Amazon
   * etc.

<a target="_blank" href="https://www.howtogeek.com/258518/how-to-use-zsh-or-another-shell-in-windows-10/">
One can configure Windows 10 to use Z shell</a> but many use <strong>git bash</strong> which remains in Bash.

Azure's <a target="_blank" href="https://docs.microsoft.com/en-us/azure/cloud-shell/features">list of its Cloud Shell features</a> includes zsh.

> Some find Apple's move exciting because Apple is leading the rest of the tech world into the future,
like Apple did about removing 3.5 mm headphone jacks on iPhone X.

So the transition will be painful, as the dream of one shell script that runs across operating systems is now dashed.


## Why Z shell is better than Bash

<a target="_blank" href="https://www.wikiwand.com/en/Z_shell">https://www.wikiwand.com/en/Z_shell</a>
says "Zsh is an extended Bourne shell with a large number of improvements, including some features of Bash, ksh, and tcsh."

Zsh also comes with an auto-update tool that makes it easier to keep installed plug-ins and themes updated. 

Can additional modules be installed on Bash to achive the same user experience advantages provided by Z shell out of the box<a target="_blank" href="https://www.howtogeek.com/362409/what-is-zsh-and-why-should-you-use-it-instead-of-bash/">*</a>:

* Automatic cd: Just type the name of the directory anywhere in the path (you don't need to specify the entire path)

* Recursive path expansion: For example “/u/lo/b” expands to “/usr/local/bin”

* Spelling correction and approximate completion: If you make a minor mistake typing a directory name, ZSH fixes it for you

* Z shell is case insensitive. 

* Z shell comes with Git client and Git completions (see http://eseth.org/2010/git-in-zsh.html#show-stashed-changes)

* Floating point support (Bash does not have)

* Support for hash data structures (requires upgrade to Bash 4)

* File globbing in Z uses character patterns that are similar, but not identical to those used in regexps. 
   Example: “He said his name was [KC]arl” to (express ambiguity). See https://www.linuxnix.com/10-file-globbing-examples-linux-unix/

* Startup/shutdown scripts via zshenv, zprofile, zshrc, zlogin, and zlogout

* Command `zmv` does massive file/directory renames. e.g. to append '.txt' to every file name run zmv –C '(*)(#q.)' '$1.txt'

* Command `zcalc` is a command-line calculator to do a quick calculation without leaving the terminal. Load it with autoload -Uz zcalc and run with zcalc

* Command `zparseopts` parses complex options (arguments) provided to shell scripts

* To display all available options for that command, along with a short description, type the command followed by -, then hit tab. Tab through to select the option shown.

More opinions:

   * http://zpalexander.com/switching-to-zsh/
   * https://www.chenhuijing.com/blog/bash-to-zsh/#%F0%9F%91%BE May 31, 2015

   ### Install on Ubuntu

   BTW, On an Ubuntu system:

   ### Verify zsh install

1. Verify the system variable that defines the shell your system defined:

   <pre><strong>echo $SHELL</strong></pre>

   If you have Bash, it would be:

   <pre>/bin/bash</pre>

   If you have Z shell, it would be:

   <pre>/usr/bin/zsh</pre>


   PROTIP: The concern is making Z shell the default, not whether to install it.


   ### Switch temporarily

6. To Switch to bash (replace your current shell with a new shell):

   <pre>exec zsh</pre>

   To switch to Bash:

   <pre>exec bash -l</strong>

   `-l` (for `--login`) avoids a source reset.

6. zsh has a builtin command to emulate different shells:

   <pre>emulate bash
   <em>perform commands</em>
   emulate -R zsh</pre>

   `-R` restores all the options to their default values for that shell.

## Z Shell plug-ins

The `~/.zshrc` file (`~` meaning in your $HOME directory) is one file that enables and disables plugins.
For example:

   <pre>plugins=(
       iterm2
       git
       zsh-autosuggestions
       yarn
       web-search
       jsontools
       macports
       node
       osx
       sudo
       thor
       docker
       zsh-syntax-highlighting
       mouse
   )
   </pre>

   The sequence is important. "prompt" must come last. history-substring-search must come before it, and syntax-highlighting must come before that.<a target="_blank" href="http://joshsymonds.com/blog/2014/06/12/shell-awesomeness-with-prezto/">*</a>

1. Define the prompt when using .zprofile or <a href="#zshrc">.zshrc</a>:

   <pre>export PS1="\n  %10F%m%f:%11F%1~%f \$ \n"</pre>


## Z shell themes

1. The powerlevel9k theme adds a right-aligned info box, integration with git and command history, incredible customization, and wraps it all up in a slick interface based on the powerline plugin for vim.

   <pre>git clone https://github.com/bhilburn/powerlevel9k.git \
   ~/.oh-my-zsh/custom/themes/powerlevel9k</pre>

2. Enable it in .zshrc:

   <pre>ZSH_THEME="powerlevel9k/powerlevel9k"</pre>

3. Customize the default prompt by defining POWERLEVEL9K_LEFT_PROMPT_ELEMENTS in your .zshrc. 
   For example, to define a minimal prompt:

   <pre>POWERLEVEL9K_LEFT_PROMPT_ELEMENTS=(vcs dir rbenv)
POWERLEVEL9K_RIGHT_PROMPT_ELEMENTS=(root_indicator background_jobs status load)
   </pre>

4. Read documentation at https://github.com/bhilburn/powerlevel9k#customizing-prompt-segments
